\chapter{서론}
\section{연구 배경}
로봇팔로 물체를 조작하려면 영상에서 대상을 찾고, 그 위치를 로봇 좌표로 변환한 뒤 실제로 잡아 옮겨야 한다. 검출 위치가 정확해도 카메라와 로봇의 좌표계가 맞지 않으면 그리퍼가 목표를 벗어난다. 목표 관절각을 계산한 뒤에도 기구 오차나 접촉 상태 때문에 파지가 실패할 수 있다. 따라서 인식과 좌표 변환, 동작 계획, 실행 결과 확인을 하나의 흐름으로 연결해야 한다.

목표는 SO-ARM101 로봇팔로 작업 공간의 다섯 개 블록을 지정 영역으로 옮기고, 이어서 블록을 적재하는 것이다. 이하에서는 SO-ARM101을 SO-101로 표기한다. 처음에는 이동형 로봇의 물체 수집을 검토했으나 과제 규격이 바뀌면서 SO-101 블록 조작으로 주제를 변경하였다. 착수·중간 단계에서는 모방학습을 시험했고, 최종 구현에는 고정 카메라 영상 처리와 역기구학을 사용하였다.

최종 시스템은 신경망 정책을 사용하지 않는다. 고전 컴퓨터 비전, 평면 캘리브레이션, 역기구학과 파지 확인을 유한상태기계로 묶었다.

실기 중에는 배경과 블록이 혼동되거나 영상 좌표와 파지 위치가 어긋났고, 그리퍼가 빈손으로 닫히는 경우도 있었다. 이를 구분하기 위해 블록 검출 좌표, IK 도달 가능성과 그리퍼 접촉 상태를 단계별로 확인하였다. 중심점에 접근할 수 없거나 파지에 실패하면 다른 후보를 실행하거나 대상을 다시 선택한다. 카메라 웹 뷰어와 대응점 기록 도구에는 판단에 필요한 영상, 관절값과 좌표를 함께 기록하였다.

\section{기존 문제점}
인식 대상과 배경의 색상이 비슷했다. 빨간 블록과 지정 영역의 테이프가 대표적이며, 나무색·노란 블록도 조명에 따라 구분이 어려웠다. 색 임계값만으로 오검출과 누락을 함께 줄이기 어려워 형상 조건을 결합하였다.

영상 좌표와 실제 파지 위치도 어긋났다. 카메라 위치가 바뀌면 기존 변환을 사용할 수 없고, 블록 윗면과 바닥의 높이 차이도 시차 오차를 만든다.

기구학 계산 결과와 실제 접촉 상태도 일치하지 않았다. IK 목표 오차가 작더라도 그리퍼 턱이 블록을 물었다고 단정할 수 없다. 파지 후 그리퍼 위치와 부하를 확인한 경우에만 운반 단계로 넘어가도록 하였다.

또한 제한시간 안에 여러 블록을 처리해야 하므로 한 블록의 파지가 반복해서 실패하면 다음 대상으로 넘어가야 한다. 이미 배치한 블록은 다시 선택하지 않도록 재시도 이력과 배치 상태를 관리하였다.

\subsection{미션 규격과 성공 조건}
블록은 $40\times40\times20\,\mathrm{mm}$ 크기이며, 서로 다른 색의 블록 다섯 개를 사용한다. 미션 시작 시 각 블록은 넓은 면을 바닥에 둔 채 지정 영역 밖에 놓인다. 블록끼리 맞닿을 수는 있지만 위아래로 겹치지는 않는다. 두 미션은 블록을 다시 배치한 뒤 각각 수행한다. 목표와 평가 조건은 표~\ref{tab:mission}과 같다.

지정 영역은 로봇 끝에서 약 25\,cm 떨어진 곳에 두며, 제어할 때는 네 꼭짓점을 로봇 베이스 좌표계에 등록한다.

신경망은 최대 하나까지 사용할 수 있으나 필수는 아니다. 최종 CV+IK 시스템은 신경망 없이 영상 처리와 기구학 계산으로 동작한다.

\subsection{세부 연구 목표}
영상에서 지정 영역 밖의 블록을 골라 로봇 좌표로 변환하고, 관절 한계와 그리퍼 방향을 고려한 접근·파지·이동 자세를 생성한다. 파지 확인과 재시도를 포함한 상태 흐름으로 블록을 반복 처리하며, 단계별 자료를 기록해 실패 지점을 추적한다. 적재 동작과 실행 자료의 학습 데이터 변환도 확장 대상으로 삼았다.

평가는 단일 블록 파지·운반, 순차 배치 시연과 180초 제한 시험으로 나누어 진행하였다. 그리퍼 회전 재시도와 하강 민감도를 조정한 뒤 치른 1차 미션 시험은 28회 모두 완료하였다. 2차 미션에는 접촉 기반 배치 전략을 적용하여 3단과 4단 적재에 성공했으며, 5단 적재는 아직 시도하지 못하였다.
