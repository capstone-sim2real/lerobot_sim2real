\section{초기 설계와 접근법 변경}
\subsection{모방학습 파이프라인의 구축과 초기 결과}
착수 단계에서는 리더암 시연으로 로봇 동작을 학습하는 방법을 검토하였다. ACT는 여러 시점의 행동을 청크 단위로 예측하는 모방학습 방법이고\cite{act}, SmolVLA는 영상·언어 입력으로 행동을 생성하는 모델이다\cite{smolvla}. LeRobot으로 시연 수집과 학습·추론 환경을 구성하고, 로봇 제어기와 정책 서버는 gRPC 원격 추론으로 연결하였다.

중간 단계까지 초록 31개, 노랑 20개, 파랑 31개, 기본 색상 30개 등 총 112개 시연 에피소드를 수집하였다. 이 가운데 초록·노랑 51개 에피소드를 합쳐 SmolVLA를 8,000스텝 파인튜닝하였다. 카메라 위치를 조정하면 관측 분포가 달라졌기 때문에 수집 환경과 실행 환경을 같게 유지해야 했다.

SmolVLA는 팔을 목표 근처까지 옮겼지만 블록을 잡지 못해 단일 블록 시험 10회가 모두 실패하였다. ACT는 제한된 위치에서 단일 블록을 잡아 옮겼으며, 액션 청크 갱신과 혼합 옵션을 조정한 뒤 \textbf{50회 중 29회(58\%)} 성공하였다.

작업 범위를 넓히고 최대 다섯 개 블록을 다루기 위해 학습 데이터를 131개 에피소드로 늘렸으나 성공 횟수는 50회 중 13회(26\%)로 줄었다. 카메라 각도와 조명이 조금만 달라져도 결과가 크게 변했다. 파지는 ACT가 담당하고 적재 위치는 IK로 계산하는 하이브리드 구조도 시험하였다. 79개 에피소드로 학습한 결과 파지는 50회 중 10회(20\%) 성공했으며 환경 변화에 따른 문제도 남았다.

이 집계는 개발 경위를 설명하는 초기 결과이며, 정식 실험 기록이 아닌 팀 내부 공유 기록에 근거한다. 개별 시행의 위치와 방향, 재시도 허용 여부 및 체크포인트를 함께 대조할 자료가 없어 최종 CV+IK와의 성능 비교에는 사용하지 않았다.

\subsection{CV+IK로의 전환 근거}
초기 실험에서는 팔이 목표 근처에 도달해도 실제 파지로 이어지지 않는 경우가 많았다. ACT의 청크 갱신과 혼합 옵션을 조정했지만 표~\ref{tab:early}와 같이 실패가 남았다. 작업 범위와 블록 수를 늘리자 카메라 각도나 조명의 작은 변화에도 성공률이 크게 달라졌다. 카메라 구성이 바뀔 때마다 시연 수집과 실행 조건도 다시 맞춰야 했다. 동작 영상만으로는 실패 원인이 관측 입력, 정책 출력, 실제 접촉 중 어디에 있는지 구분하기 어려웠다.

블록의 크기와 색상이 정해져 있고 작업 평면이 고정된 조건을 이용해 각 단계의 결과를 직접 확인하는 CV+IK 방식으로 전환하였다. 고전 CV에서 블록 중심과 방향을 찾고, 캘리브레이션으로 로봇 좌표를 구한다. IK로 후보 자세와 도달성을 검사하며, 파지 뒤에는 그리퍼 위치와 부하를 확인한다. 검출 실패, 좌표 편차, 계획 불가와 빈손 파지를 서로 다른 단계에서 처리할 수 있는 구조이다.

기존 모터 제어와 파지 확인 구조는 CV+IK 실행 경로에 재사용하였다. 전환은 실기에서 관찰한 실패, 단계별 진단 가능성과 개발 일정을 고려한 선택이다. 모방학습 실패를 데이터 양이나 특정 모델의 한계로 단정할 수 없으며, 두 방법을 같은 조건에서 비교하지도 못했다. CV+IK 방식에도 카메라 고정, 색 임계값 조정과 기구학 보정이 필요하다.

\section{블록 검출과 대상 선택}
\subsection{미터법 영상과 후보 생성}
지정 영역의 빨간 테이프가 빨간 블록과 함께 검출되는 문제가 있었다. 색 임계값만 사용하면 같은 색의 경계가 후보에 남는다. 블록의 채워진 정사각형 윤곽과 길쭉하거나 내부가 빈 테이프 윤곽을 구분하도록 형상 필터를 추가하였다. 색상으로 후보를 찾은 뒤 기하 특성으로 거르는 방식이다.

입력 영상은 캘리브레이션 결과에 따라 로봇 평면 좌표에 대응하는 1\,mm/pixel 정사영 영상으로 변환한다. HSV 색 공간에서 색별 마스크를 만든 뒤 타원형 커널로 열림·닫힘 연산을 적용한다. 외부 윤곽선에서 면적, 회전 사각형과 형상 지표를 계산하므로 물체 크기 조건을 밀리미터 단위로 지정할 수 있다.

후보는 면적, 종횡비와 채움 비율로 판별한다. 맞닿은 블록의 윤곽이 합쳐지거나 팔에 가려져 면적이 줄면 실제 블록도 제외될 수 있다. 이를 줄이기 위해 SELECT에서는 HOME으로 돌아가 시야를 확보하고 매 사이클 새 영상을 검출한다. 형상 필터 적용 전후의 검출 정확도는 따로 측정하지 않았다.

\subsection{색 기준점 할당과 영역 필터}
후보의 대표 색상·채도를 $(H,S)$, 기준점을 $(H_c,S_c)$라고 하면 구현의 거리 함수는 다음과 같다.
\begin{equation}
\Delta H=\min(|H-H_c|,180-|H-H_c|),\qquad
d=\sqrt{\left(\frac{2\Delta H}{128}\right)^2+
\left(\frac{S-S_c}{128}\right)^2}.
\end{equation}
색상은 원형 범위로 처리하고, 한 색에 기준점이 여러 개 있으면 가장 가까운 거리를 사용한다. 전체 후보--색 쌍을 거리순으로 정렬한 후 이미 할당한 후보나 사용한 색을 제외하면서 탐욕적으로 할당한다. 거리가 0.35를 넘는 후보는 미할당 상태로 남긴다.

동일한 블록이 여러 색 마스크에 잡힌 경우에는 채움 비율과 solidity의 곱이 높은 후보를 우선하여 가까운 후보를 병합한다. 지정 영역 내부 후보는 블록 중심 좌표로 판정하여 색 할당 전에 제외한다. 이 순서를 통해 이미 배치한 블록이 색 할당을 차지하여 영역 밖의 후보를 가리는 상황을 줄였다.

1차 미션은 현재 검출된 후보 가운데 베이스 원점에서 가까운 블록을 먼저 선택한다. 색상별 블록이 하나씩이라는 조건을 이용하여 색 이름을 재시도 식별자와 슬롯 예약의 키로 사용한다. 동일한 색이 여러 개 존재하는 일반 작업으로 확장하려면 별도의 물체 추적 식별자가 필요하다.

\section{캘리브레이션과 좌표 관리}
\subsection{대응점 수집 절차}
영상의 블록 중심과 실제 그리퍼 접근 위치가 어긋나지 않도록 대응점 수집 조건을 정하였다. 블록 윗면과 빈 테이블은 높이가 다르며, 같은 위치에서 턱이 닿아도 손목 회전에 따라 FK 기준점 좌표가 달라질 수 있다. 대응점 수뿐 아니라 기준 평면과 손목 자세, 기록 항목을 함께 관리하였다.

대응점 하나를 기록할 때 같은 블록 위치에서 두 장면을 촬영하였다. 먼저 그리퍼 기준점을 블록 윗면 중앙에 맞추고 관절값과 접촉 자세 영상을 저장한다. 블록을 그대로 둔 채 팔을 물린 뒤 윗면이 드러난 영상에서 픽셀 중심을 찾는다. 첫 장면의 관절값으로 구한 FK 좌표와 두 번째 장면의 영상 좌표를 같은 점으로 연결한다. 그림~\ref{fig:calibration-pair}는 아홉 대응점 가운데 P4의 수집 장면이다.

손목 회전은 중립 근처로 유지한다. 같은 턱 접촉 상태라도 회전축과 URDF 그리퍼 기준점의 위치 관계 때문에 기록되는 FK 좌표가 바뀔 수 있기 때문이다. 따라서 좌표값만 남기는 대신 관절각을 보관하고, 캘리브레이션 자세와 런타임 파지 자세의 차이를 줄이는 절차를 사용하였다. 카메라를 다시 고정한 경우에는 대응점을 다시 수집하여 변경된 카메라 배치에 맞는 변환을 적용하였다.

\subsection{좌표 품질과 카메라 안정성 평가}
좌표 변환은 적합 RMS와 최대 LOO 오차로 평가하였다. 목표는 각각 5\,mm 미만과 8\,mm 미만이었다. 대응점은 5점, 9점, 15점으로 늘린 뒤 두 차례에 걸쳐 아홉 점을 다시 수집하였다(표~\ref{tab:calibration-history}). 최종 결과는 RMS 5.1454\,mm와 최대 LOO 13.5348\,mm로 두 기준에 미달했지만, 직전 결과인 8.18\,mm와 26.64\,mm보다 감소하였다. 남은 좌표 오차는 파지 후보 보정과 센서 확인으로 보완하였다.

카메라 안정성은 기준 영상과 현재 영상의 대응 코너 이동량으로 평가한다. 개별 코너의 검출 변동에 민감한 최댓값 대신 p95를 주요 지표로 사용하며, 설계 기준은 10분간 2\,pixel 미만이다. 실기 평가에서는 약 1분의 단축 검사를 수행하였다.

\section{역기구학과 궤적 실행}
\subsection{손목 과열에 대응한 중립 방향 선택}
초기에는 그리퍼 yaw를 베이스 기준으로 고정하였다. 팔이 선회할수록 손목이 반대로 비틀렸고, 결국 손목 서보가 과열 보호로 정지하였다. 이후에는 작업 위치별 중립 손목 방향을 기준으로 블록 면을 정렬하여 파지 방향을 유지하면서 손목 회전을 줄였다.

파지 계획은 선택한 블록의 좌표와 방향, 캘리브레이션의 파지 높이를 입력으로 받는다. URDF에 정의된 그리퍼 기준 좌표계를 목표 프레임으로 사용하고 접근축이 아래를 향하는 자세를 우선한다. 위치마다 가능한 관절 조합이 다르므로, FK로 구성한 자세 시드를 사용하고 어깨 선회각에 여러 오프셋 후보를 적용하여 해를 찾는다. 선회각의 오프셋 후보는 $0^\circ,\pm6^\circ,\pm12^\circ$이다.

손목 방향은 해당 위치에서 손목 회전각이 중립 근처가 되는 yaw를 기준으로 정한다. 블록 방향을 $\theta_b$, 중립 방향을 $\theta_n$이라고 하면, 정사각형의 대칭성을 이용해 다음 후보 가운데 중립과의 각도 차이가 가장 작은 방향을 선택한다.
\begin{equation}
 \theta^*=\arg\min_{\theta\in\{\theta_b+k\cdot90^\circ\mid k=0,1,2,3\}}
 \big|\operatorname{wrap}_{[-180^\circ,180^\circ)}(\theta-\theta_n)\big|.
\end{equation}
이 규칙은 블록 면을 따라 정렬하면서 중립 자세에서 벗어나는 손목 회전을 줄인다. 변경 전후의 온도 상승량과 연속 운용 시간은 비교하지 않았다.

\subsection{좌표 편차와 대체 파지 후보}
기구와 좌표 오차를 줄이기 위해 파지 목표에 반경·접선 방향의 경험적 보정값을 더한다. 1차 미션에서는 원거리 보정도 적용하였다. 보정량은 반경 200\,mm에서 0\,mm이고, 320\,mm까지 선형으로 늘어나 최대 20\,mm가 된다. 원거리에서는 접근 기울기도 조정한다.

중심점 후보의 계획 실패와 블록 전체의 파지 불가능을 구분하기 위해, 중심점에 도달하지 못하더라도 주변 후보의 도달성 검사를 이어가도록 파지 조건을 보완하였다. 설정된 네 보정 후보는 반경·접선 좌표로 $(0,15)$, $(-15,0)$, $(0,-15)$, $(15,0)$\,mm이다. IK 게이트를 통과한 후보만 실행하고, 실행 후 빈손으로 판정되면 다음 후보로 진행한다. 이 구조는 계획 단계의 거부와 실제 파지 실패를 각각 처리한다.

네 보정 후보가 모두 빈손으로 판정되는 사례를 분석한 결과, 위치 보정만으로는 부족하고 그리퍼 각도가 검출된 파지선과 어긋나 파지가 실패하는 경우가 있었다. 파지선은 검출된 블록의 타원 윤곽에서 가장 가까운 접선 방향으로 계산한다(그림~\ref{fig:camera-overlay}의 노란 수직선). 이에 네 후보가 모두 실패하면 그리퍼를 90도 회전시켜 같은 위치에서 한 번 더 시도하고, 그래도 실패하면 기존 흐름대로 다음 후보나 재선택으로 넘어가도록 재시도 로직을 보완하였다.

후보 탐색은 검출 위치 주변의 오차를 경험적 보정값으로 처리한다. 파지 직전 실제 턱 위치를 영상으로 추정하지는 않는다. 후보가 늘면 동작 시간도 길어지므로 후보별 센서 결과와 소요 시간을 함께 기록하였다.

\subsection{도달성 검사와 접근 높이}
IK 결과는 모델 좌표에서의 위치 오차와 기울기 오차를 확인한 후 사용한다. 실행 전 계획의 허용 오차는 위치 15\,mm, 기울기 $6^\circ$로 설정하였다. 높은 접근점이 관절 한계에 걸릴 수 있으므로 최소 높이와 탐색 간격을 두고 가능한 접근 높이를 찾는다.

위치 15\,mm는 모델 안에서 계획 후보를 거르는 허용값이다. RMS 5\,mm와 최대 LOO 8\,mm는 대응점 정합의 개발 목표로, 세 값은 평가 대상이 다르다. 실제 파지 여유를 측정해 정한 값도 아니다. 그리퍼 개방 명령 역시 정규화 위치값이어서 실제 턱 간격으로 바로 환산할 수 없다. 따라서 이 값들을 합산해 총오차로 해석하지 않으며, IK 통과가 폭 40\,mm 블록의 파지를 보장하지도 않는다.

인식 경로는 반경 320\,mm의 작업 영역 필터로 제어 대상을 제한한다. 이후 각 목표의 높이와 방향에 대해 IK를 풀어 실행 가능성을 판단한다. 관측 범위와 자세별 도달성을 두 단계로 검사하는 구조이다.

\subsection{측정 자세에서 시작하는 관절 보간}
웨이포인트 사이의 동작은 관절 공간에서 보간한다. 시작 자세 $\boldsymbol{q}_0$는 직전에 보낸 명령이 아니라 현재 측정값이며, 목표를 $\boldsymbol{q}_1$이라 하면 보간점은 다음과 같이 표현할 수 있다.
\begin{equation}
\boldsymbol{q}(\alpha)=(1-\alpha)\boldsymbol{q}_0+\alpha\boldsymbol{q}_1,
\qquad 0\leq\alpha\leq1.
\end{equation}
보간 과정에서 틱당 관절 변화량을 제한하고, 로봇 입출력 단계의 상대 목표 클램프를 추가 적용한다. 측정 자세에서 시작하면 이전 동작이 목표에 충분히 도착하지 못한 경우에도 다음 궤적이 명령상의 가상 위치에서 시작하는 것을 줄일 수 있다.

\subsection{1차 미션: 지정 영역의 동적 슬롯 배치}
1차 미션은 지정 영역 내부에 먼 행 세 개와 가까운 행 두 개의 슬롯을 구성한다. 영역 네 꼭짓점과 정규화 좌표를 이용하여 슬롯 중심을 계산하고, 각 슬롯의 해제점과 상공 자세를 IK로 구한다. 기본 정규화 좌표는 $(0.14,0.20)$, $(0.50,0.20)$, $(0.80,0.20)$, $(0.32,0.76)$, $(0.68,0.76)$이다. 선택한 색은 예약한 슬롯을 유지하여 재시도 때 배치 위치가 불필요하게 바뀌는 것을 줄인다.

운반 경로는 파지 위치와 배치 위치의 높이·도달성을 고려하여 계산한다. 필요하면 베이스 쪽으로 당긴 경유점에서 더 높은 통과 자세를 만든 후 목표 슬롯 상공으로 이동한다. 해제 높이는 캘리브레이션의 평균 파지 높이에 가정한 여유 5\,mm를 더해 계산한다.

1차 미션은 HOME에서 새 프레임을 받아 지정 영역 밖의 검출이 연속 5초 동안 없으면 완료 상태로 전이한다. 중복되거나 오래된 프레임은 완료 시간에 누적하지 않는다. 이 판정은 관측된 블록 중심에 의존하므로, 검출 누락과 실제 경계 걸침을 포함한 물리적 완료 판정에는 한계가 있다.

\subsection{재시도와 실행 종료}
대상별 재시도 횟수는 한 순회 안에서만 제한한다. 남은 색이 모두 보류되면 시도 기록을 유지한 채 새 순회를 시작한다. 이 구조에서는 누적 재시도 횟수가 계속 늘어날 수 있어 1차 미션 실행기의 내부 FSM 시간 제한을 비활성화하고 외부 타이머를 사용하였다.

제한시간 시험에서는 외부 타이머가 180초에 종료 신호를 보낸다. 종료 신호를 받은 뒤 그리퍼 개방과 홈 복귀를 시도하므로 전체 모터 동작이 180초 안에 끝나는지는 별도로 판정해야 한다.

\subsection{2차 미션: 접촉 기반 적재 구조}
2차 미션은 공통 파지·확인 흐름에 적재용 PLACE 전략을 연결하는 구조이다. 구현된 적재 프리미티브는 기록된 타워 접근 자세와 하강 키프레임을 사용하고, 하강 사이에 관절 부하의 기준값 대비 변화를 확인한다. 접촉이 감지되면 실행한 궤적에서 일부 되돌린 뒤 해제하며, 키프레임 끝까지 접촉이 없으면 경고를 남기고 해제한다.

초기에는 블록 높이를 누적하여 해제 높이를 계산하는 방식을 검토했으나, 구현은 관절 키프레임과 접촉 감지를 결합한 하강 방식으로 구성하였다. 2차 미션의 성공 조건은 해제 후 적재 상태를 5초 이상 유지하는 것이다.

적재 실기에는 정확도 개선 조치를 적용한 뒤 등록한 타워 접근·하강 자세를 사용하였다.

\subsection{Task3: 데이터셋 자동 수집 구조}
CV+IK 경로는 센서값과 검출 결과로 대상 선택, 파지와 배치를 판정한다. 이 실행 과정의 관측·동작·성공 여부를 기록하여 리더암 없이 에피소드를 자동 수집하도록 확장하였다. ACT와 SmolVLA용 시연은 리더암으로 한 에피소드씩 수집했지만, 이 방식은 같은 실행 루프를 반복해 데이터를 저장한다.

로봇 I/O 경계에 \texttt{RecordingRobotIO} 데코레이터를 두었다. 명령 직전의 관측과 안전 제한을 거쳐 실제 전송된 액션을 한 프레임으로 묶어 LeRobotDataset 형식(observation.state, observation.images.top, action, task)으로 저장한다. PICK/VERIFY/TRANSPORT 코드는 1차 미션과 같다. 초기에는 안전 제한 전의 요청 액션이 기록되었으나, 이를 실제 전송값으로 수정하였다.

Task3은 home$\to$탐지$\to$파지$\to$운반$\to$배치$\to$home 복귀를 한 에피소드로 기록하며, 파지·운반·배치가 모두 성공하고 이어지는 home 복귀까지 끝난 경우에만 저장한다. 1차/2차 미션과 달리 그리퍼 회전이나 위치 보정 재시도 없이 최초 파지 1회만 시도하도록 제한하여, 실패 후 복구 동작이 섞이지 않은 깨끗한 시연만 남도록 설계하였다. 지정 영역 밖의 블록이 5초간 탐지되지 않으면 한 라운드가 끝난 것으로 보고 작업자에게 블록 재배치를 요청한다.

저장 형식은 관절 데이터를 담는 parquet, 영상을 담는 MP4와 에피소드·작업 메타데이터로 구성된다(그림~\ref{fig:task3-structure}).

\subsection{안전 처리와 실행 기록}
안전장치는 관절 보간의 변화량 제한, 상대 목표 클램프, IK 게이트와 파지 확인에 나누어 적용하였다. 하강 중 턱이 물체에 걸렸는데도 명령을 계속 보내면 블록을 밀거나 팔이 구속될 수 있다. 측정 관절이 명령을 따라오지 못하는 정도를 검사해 하강을 중단하고, 그리퍼를 닫은 뒤 파지 여부를 따로 판정한다. 하강 중단 기준은 \texttt{descent\_max\_lag} 8.0, \texttt{descent\_blocked\_tol} 4.0으로 조정하였다.

정상 종료와 예외 발생 시 모두 그리퍼 개방, 홈 복귀와 연결 해제를 시도하도록 종료 절차를 구성하였다. 통신이나 장비 오류가 지속되면 정리 동작이 실패할 수 있으므로 오류와 최종 상태를 함께 기록한다. 연결 해제 후에는 팔의 자세 유지를 위해 토크를 유지한다. 모터를 구동하지 않는 사전 경로 검사와 실제 장비 시험은 별도로 수행하였다.

실험마다 적용 설정, 대응점·관절값, 상태 전이와 단계별 사진을 저장하여 실패 단계와 실행 조건을 추적하였다.
