## 과거 진단의 보존

`experiments/2026-09-08/session_20260908_AcC1p4/`와 보고서의 `evidence/20260908/`가 초기 진단의 근거다. 해당 자료는 최신 결과와 구분하여 4장 후반에서 실패 분석에 사용한다.

- `task1_run.txt`: 30Hz, 슬롯 반경 보정 0mm, 외부 180초 제한. 후보 시작 14회, HELD 4회, EMPTY 9회, 판정 전 중단 1회; PICK 진입 6회, 슬롯 해제 4회, DONE 전이 0회. 마지막 파란 블록 잔류 관찰과 함께 미완료로 판정한다.
- `analysis/summarize_evidence.py`: 위 로그의 후보·상태·시간 재집계. 빨강 첫 PICK 51.492초, 최초 선택부터 재선택 뒤 해제까지 69.815초. 종료 신호와 물리적 정지 시각은 미기록이다.
- `drift_60s.csv`와 재검사 CSV: 각각 약 60.5초·12표본. 표본별 p95 중 최댓값 2.775/0.514px이며 10분 검증이 아니다.
- V1/V2 거리 19.94/7.11mm는 다른 자세의 블록–FK 거리다. 실제 턱 위치의 독립 측정, 보정 전후 비교나 백래시의 단일 원인 증거가 아니다.
- 노란 블록 45Hz 진단 3조건은 첫 위치 성공, 안쪽 두 시도 빈손이다. 동일 조건 반복 성공률로 합치지 않는다.
- P4 사진과 관절 원기록은 9월 8일 대응점을 설명하며 최신 9월 13일 수집 사진으로 표시하지 않는다.
- 로컬 94건·Orin 99건 소프트웨어 시험 통과는 당시 기록이다. 최신 코드의 테스트 결과 또는 이번 문서 작업에서 재실행한 결과가 아니다.

## 아직 집계하지 않은 항목

1. 최신 30회 및 20회의 시행별 초기 배치·소요 시간·개별 후보 결과와 정확한 실험용 코드 버전.
