## 작업 범위

새 하드웨어 시험과 로봇 제어 코드 변경은 수행하지 않았다. 94/99건 소프트웨어 테스트 통과는 기존 개발 기록이며 이번 문서 작업에서 재실행한 결과가 아니다. 추가 반복 평가 양식은 헤더만 있는 계획 상태다.

변경은 별도 보고서 워크트리의 최종보고서 디렉터리에 한정한다. 미추적 `docs/PPT/`는 이번 커밋과 수정에 포함하지 않았다. 원본 착수/중간보고서, 동료 PDF, 구현 코드와 실험 원본은 변경하지 않았다. `git diff --check` 통과. 수정 전 스냅샷의 CRLF CSV는 원본 바이트를 유지하기 위해 `git -c core.whitespace=cr-at-eol diff --cached --check`로 검사했다.

최신 빌드 로그는 `build/final_report.log`와 `/tmp/so101-report-concise-build.log`, 이번 문구 검토 이미지는 Git 제외 디렉터리 `review/concise/`에 있다. 그림 4.2 검토 이미지는 `review/rectangle/`에 있다. 문체 개정의 전체 렌더링 검토는 `review/editorial/`에 있다. 이전 설계 개정 검토는 `review/design-20260911/`, 문체 수정 직전 사본은 `review/editorial-before/`에 있다. 재집계 방법은 `analysis/README.md`, 회의 해석과 원본 연결은 `MEETING_REVIEW_20260911.md` 및 `SOURCES.md`에 기록했다.

PDF 전체의 추출 텍스트에서 일 단위 한글/영문 날짜, 커밋과 실행 ID, 저장소 파일명 및 정리 대상 코드 용어가 남지 않았음을 확인했다. 학번과 실험 수치, 참고 문헌 URL은 날짜나 저장소 파일명으로 처리하지 않았다. 소스의 그림 참조 경로와 제출에 포함하지 않는 출처/검증 문서에는 상세 식별자를 유지했다.

그림 4.2의 지정 영역을 200×100mm 직사각형으로 수정하고 재빌드했다. 중심은 원자료의 네 꼭짓점 평균과 같고, 가로/세로 길이를 생성 좌표로 검증했다. 그림 소스에서 도형과 표시의 두 줄만 달라졌고 잔차 화살표는 동일하다. 최종 PDF는 42쪽이며 본문 25쪽의 수정된 도형을 확대 확인했다. 공백을 제외한 페이지별 추출 텍스트의 변화는 그림 4.2가 있는 페이지에 한정된다. 최종 빌드 경고 없음, 자산 16개 및 원자료 해시 검증과 `git diff --check` 통과.

시행 규모 표기를 중복 정리한 최신 PDF는 42쪽이다. 문구가 바뀐 PDF 2/30/31/32/35/39쪽을 렌더링하여 확인했고 빌드 경고와 대체문자가 없다. 실험 조건표의 실제 시행 수와 드리프트 방법의 횟수, 모든 표의 데이터 행 및 16개 자산 해시를 유지했다. 반영하지 않은 진단 중심 재구성안은 철회 상태이며 이번 작업은 반복 문구에 한정한다.
