# 초안 검토 기록

검토일: 2026-09-10. 보고서 산출물만 검증했으며 하드웨어 동작이나 새로운 미션 실험은 수행하지 않았다.

- `bash build.sh`: rootless Podman의 pdfLaTeX/BibTeX/latexmk 빌드 성공.
- 최종 PDF: A4, 36쪽(표지 1 + 목차 3 + 본문 30 + 참고 문헌 2), 6,814,662바이트.
- 최종 LaTeX 로그: undefined reference, LaTeX Warning, Overfull/Underfull 경고 없음.
- 본문 인용 키와 참고 문헌 8개 항목의 순서 일치 확인.
- PDF 텍스트 추출 성공. 5개 장 제목, 핵심 수치 및 대체문자 U+FFFD 부재 확인.
- 29/50=58% 산술 확인. 두 드리프트 CSV의 12개 행 및 프레임별 p95 최댓값 2.775/0.514px 재계산 확인.
- 초벌 PDF 전체 페이지를 축소 모음으로 시각 검토. 최종 렌더의 1~33쪽 중 목차 4쪽을 제외한 모든 페이지가 초벌 렌더와 픽셀 단위로 동일함을 확인. 변경된 목차와 결론·참고 문헌, 구조도·상태도·그래프 페이지를 개별 확대 검토.
- 사진 원본과 영상 표본 프레임을 검토하고 캡션의 시기·성공/실패 구분 확인. 원본 영상 전 프레임 판독이나 미션 공식 채점은 수행하지 않음.
- 작업 시작 시 기록한 기존 `docs/report/` 파일 108개의 SHA-256이 모두 유지됨. 학과 클래스 복사본도 원본과 동일.
- 그림·CSV 자산 11개의 해시 및 출처를 `asset_manifest.json`에 기록. 직접 복사한 8개 파일은 원본과 바이트 단위로 동일함을 확인.
- `bash -n build.sh`, `git diff --check` 통과. 기존 추적 파일 변경 없음.

## main 기반 보고서 커밋 검토

새 워크트리로 복사한 28개 파일의 해시가 원본과 동일함을 확인한 뒤 README에 브랜치 기준 설명을 추가했다. 스테이징 검토에서 학과 원본 클래스의 EOF 빈 줄과 원본 CSV의 CRLF는 그대로 보존했다. 클래스만 제외하고 CRLF를 허용한 `git diff --cached --check`를 통과했다. 기존 검토 로그·렌더링은 원본 체크아웃의 생성물이며 이 커밋에는 포함하지 않는다.
