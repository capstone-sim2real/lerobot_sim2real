\section{초기 설계와 접근법 변경}
\subsection{모방학습 파이프라인의 구축과 초기 결과}
착수 단계에서는 리더암의 시연으로 로봇 동작을 학습하는 방식을 검토하였다. ACT는 여러 시점의 행동을 청크로 예측하는 모방학습 접근법이며\cite{act}, SmolVLA는 영상·언어 입력을 행동 생성에 연결하는 모델이다\cite{smolvla}. 팀은 LeRobot을 이용하여 시연 수집과 학습·추론 환경을 구성하고 두 접근법의 초기 동작을 확인하였다. 중간보고서에는 데이터 수집, 모델 학습, gRPC 원격 추론 연결 및 정책 실행 경험을 정리하였다.

중간보고서 기준으로 초록 31개, 노랑 20개, 파랑 31개, 기본 색상 30개로 총 112개 시연 에피소드를 확보하였다. 초록·노랑 51개 에피소드를 병합하여 SmolVLA를 8,000스텝 파인튜닝한 초기 학습 기록도 기술하였다. 이는 중간 단계의 보고 내용이며, 현재 모든 원본 데이터셋과 체크포인트를 재검증하여 산출한 최신 총량을 뜻하지 않는다. 초기 카메라 위치를 조정한 뒤에는 관측 분포가 바뀌므로 데이터와 실행 환경의 일치 여부를 다시 확인해야 했다.

SmolVLA의 초기 실기 실행에서는 목표 근처로 팔이 이동하였으나 안정적인 파지를 확인하지 못하였다. 일반 ACT에서는 제한된 위치 범위의 단일 블록 파지·이동이 관찰되었고, 액션 청크 갱신 및 혼합 옵션을 조정하였다. 팀이 최종보고서 작성 시 제공한 집계에 따르면 \textbf{튜닝 후 단일 블록 이동은 50회 중 29회 성공하여 성공률이 58\%}였다. 이는 1차 미션의 다섯 블록 전체 완주율이나 최종 CV+IK 시스템의 성공률이 아니다.

중간보고서에 기재한 튜닝 전 약 15\%는 별도의 시행 횟수가 남지 않은 잠정 관찰값이다. 따라서 58\%와의 차이로 정량적인 성능 개선 폭을 계산하지 않는다. 또한 데스크톱과 Orin Nano의 동일 조건 추론 비교가 충분하지 않으므로 원격 추론이 항상 우수하다고 결론 내리지 않는다. 원격 추론은 초기 개발에서 구축한 기능이며 최종 CV+IK 경로의 필수 구성요소는 아니다.

\subsection{CV+IK로의 전환 근거}
중간 단계에서는 여러 정책 후보를 동시에 완성하는 방향을 검토했지만, 데이터 수집과 학습, 실제 로봇 튜닝 및 배치 로직을 함께 진행해야 했다. 초기 실험에서 파지 위치와 동작 복구가 충분히 안정적이지 않았고, 카메라 구성 변화에 따른 데이터 정비도 필요하였다. 팀은 제한된 일정과 과제의 고정된 물체·평면 조건을 고려하여 최종 실행 경로를 고전 CV+IK로 정리하였다.

이 방식에서는 블록 중심과 각도를 영상에서 명시적으로 계산하고, 각 단계의 입력과 출력 좌표를 관찰할 수 있다. 따라서 검출 실패, 좌표 변환의 편차, IK 계획 불가, 빈손 파지를 단계별로 구분할 수 있다. 이미 구축한 모터 제어, 캘리브레이션 경험과 상태별 파지 확인 구조는 전환 후에도 활용하였다. 반면 시연 학습을 생략하는 대신 카메라 고정, 색 임계값, 좌표 변환과 기구 보정에 노력이 필요하게 되었다.

이는 동일 조건의 전면적인 알고리즘 비교를 통해 최적 방법을 입증한 결과가 아니라, 확보한 실험 관찰과 개발 제약에 근거한 설계 선택이다. 후보 중단 기준을 사전에 정한 완전한 비교 실험은 수행하지 못하였으며, 이 점은 자문의견 대응에서 한계로 함께 설명한다. 최종 실행에서는 ACT·VLA를 호출하지 않고 고전 영상 처리 결과와 기구학 계산으로 행동을 구성한다.

\section{블록 검출과 대상 선택}
\subsection{미터법 영상과 후보 생성}
입력 영상은 캘리브레이션을 이용해 로봇 평면 좌표에 대응하는 미터법 영상으로 변환한다. 분석 기준 설정은 1\,mm/pixel이다. 이 영상에서 HSV 변환 후 색별 마스크를 만들고 타원형 커널의 열림·닫힘 연산을 적용한다. 이후 외부 윤곽선을 찾아 면적, 회전 사각형 및 형상 지표를 계산한다. 원본 픽셀 면적을 직접 기준으로 삼는 경우와 달리 물체 크기 조건을 밀리미터 단위로 설정할 수 있다.

\subsection{색 기준점 할당과 영역 필터}
후보의 대표 색상·채도를 $(H,S)$, 기준점을 $(H_c,S_c)$라고 하면 구현의 거리 함수는 다음과 같다.
\begin{equation}
\Delta H=\min(|H-H_c|,180-|H-H_c|),\qquad
d=\sqrt{\left(\frac{2\Delta H}{128}\right)^2+
\left(\frac{S-S_c}{128}\right)^2}.
\end{equation}
색상은 원형 범위로 처리하고, 한 색에 기준점이 여러 개 있으면 가장 가까운 거리를 사용한다. 전체 후보--색 쌍을 거리순으로 정렬한 후 이미 이름이 정해진 후보나 사용된 색 슬롯을 건너뛰며 순차적으로 할당한다. 설정된 최대 거리 0.35를 넘는 후보는 색을 강제로 붙이지 않는다. 이는 규칙 기반의 탐욕적 할당이며 전역 최적 할당을 보장하는 알고리즘으로 설명하지 않는다.

동일한 블록이 여러 색 마스크에 잡힌 경우에는 채움 비율과 solidity의 곱이 높은 후보를 우선하여 가까운 후보를 병합한다. 지정 영역 내부 후보는 색 할당보다 먼저 제외한다. 그래야 이미 배치한 블록이 자신의 색 슬롯을 차지하여 영역 밖의 후보를 가리는 상황을 줄일 수 있다. 이 제외 판정은 블록 중심 좌표를 기준으로 하므로, 블록 전체의 경계 걸침 허용 범위를 판정하는 경기 채점기와 동일하지 않다.

1차 미션은 현재 검출된 후보 가운데 베이스 원점에서 가까운 블록을 먼저 선택한다. 색상별 블록이 하나씩이라는 조건을 이용하여 색 이름을 재시도 식별자와 슬롯 예약의 키로 사용한다. 동일한 색이 여러 개 존재하는 일반 작업으로 확장하려면 별도의 물체 추적 식별자가 필요하다.

\section{캘리브레이션과 좌표 관리}
\subsection{대응점 수집 절차}
캘리브레이션에서는 작업 공간의 여러 위치에 블록을 놓고 윗면 중앙에 그리퍼 기준점을 맞춘 뒤, 영상의 픽셀 좌표와 관절 상태로 계산한 FK 좌표를 함께 기록한다. 베이스 좌표는 밀리미터로 유지하고 IK 라이브러리의 단위와 경계에서 변환한다. 각 점의 이름, 픽셀 좌표, 로봇 좌표, 관절값과 사진을 함께 보관하면 잘못 기록한 점을 사후에 검토할 수 있다.

손목 회전은 중립 근처로 유지한다. 같은 턱 접촉 상태라도 회전축과 URDF 그리퍼 기준점의 위치 관계 때문에 기록되는 FK 좌표가 바뀔 수 있기 때문이다. 따라서 좌표값만 남기는 대신 관절각을 보관하고, 캘리브레이션 자세와 런타임 파지 자세의 차이를 줄이는 절차를 사용하였다. 카메라를 다시 고정한 경우에는 이전 대응점을 그대로 활성화하지 않고 새 세션의 자료와 구분하였다.

\subsection{후보와 활성 설정의 분리}
실험 디렉터리에는 여러 번의 촬영, 재시도와 적합 후보가 함께 남아 있다. 9월 8일 세션의 실제 채택 자료는 텔레오퍼레이션 하위 디렉터리의 아홉 점과 해당 적합 결과이다. 상위 디렉터리의 이전 점 또는 후보 JSON을 활성 설정으로 간주하면 다른 실험의 결과를 섞을 수 있다. 본 보고서는 채택된 아홉 점의 적합 보고서를 4장의 기준 자료로 사용하였다.

캘리브레이션 품질 확인에는 적합 RMS와 최대 LOO 오차를 사용한다. 코드에 등록된 변환이 있다는 사실과 품질 기준을 만족했다는 사실은 별개이다. 실제 채택 자료는 RMS 및 LOO 기준에 미달하였으나 후속 관찰을 위해 사용되었으며, 그 한계를 실험 결과에 명시한다. 단순히 다시 점을 적합했다는 이유만으로 정확도가 개선되었다고 판단하지 않는다.

카메라 안정성은 기준 영상과 현재 영상에서 대응하는 코너의 이동량으로 관찰한다. 설계상 세션 게이트는 10분간 p95 드리프트 2\,pixel 미만이다. 확보된 9월 8일 자료는 약 1분씩의 단축 검사이므로 10분 안정성 검증을 대신하지 않는다. 개별 코너의 최대 변위는 오검출에 민감할 수 있어 p95와 함께 해석한다.

\section{역기구학과 궤적 실행}
\subsection{중립 손목 방향과 파지 후보}
파지 계획은 선택한 블록의 좌표와 방향, 캘리브레이션의 파지 높이를 입력으로 받는다. URDF의 \texttt{gripper\_frame\_link}를 목표 프레임으로 사용하고 접근축이 아래를 향하는 자세를 우선한다. 위치마다 가능한 관절 조합이 다르므로, FK로 구성한 자세 시드를 사용하고 shoulder pan에 여러 오프셋 후보를 적용하여 해를 찾는다. 현재 설정의 pan 후보는 $0^\circ,\pm6^\circ,\pm12^\circ$이다.

손목 방향은 해당 위치에서 wrist roll이 중립 근처가 되는 yaw를 기준으로 정한다. 블록 방향을 $\theta_b$, 중립 방향을 $\theta_n$이라고 하면, 정사각형의 대칭성을 이용해 다음 후보 가운데 중립과의 각도 차이가 가장 작은 방향을 선택한다.
\begin{equation}
 \theta^*=\arg\min_{\theta\in\{\theta_b+k\cdot90^\circ\mid k=0,1,2,3\}}
 \big|\operatorname{wrap}_{[-180^\circ,180^\circ)}(\theta-\theta_n)\big|.
\end{equation}
이렇게 하면 블록의 면에 그리퍼를 정렬하면서도 작업 공간을 가로질러 이동할 때 손목이 불필요하게 비틀리는 동작을 줄일 수 있다. 중립에 가까운 계산 결과가 실제 케이블 간섭이나 장시간 서보 온도를 모두 검증했다는 의미는 아니다.

기구 및 좌표 오차를 고려하여 파지 목표에 반경·접선 방향 보정값을 적용한다. 일반 파지 보정과 1차 미션의 원거리 보정은 서로 다른 단계의 설정이다. 현재 1차 미션 설정은 반경 200\,mm에서 추가 보정 0\,mm, 320\,mm에서 최대 20\,mm가 되도록 선형 증가시키며, 원거리에서는 추가 기울기도 적용한다. 이 값은 구현에 사용된 조건으로서, 모든 위치에서 오차를 제거함을 입증한 측정 결과가 아니다.

기본 파지가 실패한 경우에는 반경·접선 방향으로 이동한 후보를 순서대로 검토한다. 설정된 네 보정 후보는 $(0,15)$, $(-15,0)$, $(0,-15)$, $(15,0)$\,mm이다. 각 후보는 IK 게이트를 통과한 경우에만 실행한다. 원래 위치에서 조금 벗어나 잡는 재시도는 실제 블록과 턱의 상대 위치를 새로 측정하는 시각 보정과 구별된다. 잘못된 보정이 실패를 줄이는지 여부는 위치와 방향을 통제한 별도 실험으로 확인해야 한다.

\subsection{도달성 검사와 접근 높이}
IK 결과는 계산된 위치 오차와 기울기 오차를 확인한 후 사용한다. 현재 설정의 최대 위치 오차는 15\,mm, 최대 기울기 오차는 $6^\circ$이다. 이는 실행 전 계획을 거르는 조건으로, 실제 파지 정밀도의 허용 범위나 실측 성능을 뜻하지 않는다. 높은 접근점이 관절 한계에 걸릴 수 있으므로 최소 높이와 탐색 간격을 두고 가능한 접근 높이를 찾는다.

최종 인식 경로에는 반경 320\,mm의 작업 영역 필터가 있으나, 이 값은 설정된 관측 범위이다. IK의 모든 자세에 대한 물리적 최대 도달 반경을 뜻하지 않는다. 반대로 화면상 관측 영역 안에 있는 블록이라도 요구하는 높이와 방향의 IK가 가능하다고 보장되지 않는다. 검출 범위와 개별 목표의 기구학적 도달 가능성을 단계적으로 확인하도록 구성하였다.

\subsection{측정 자세에서 시작하는 관절 보간}
웨이포인트 사이의 동작은 관절 공간에서 보간한다. 시작 자세 $\boldsymbol{q}_0$는 직전에 보낸 명령이 아니라 현재 측정값이며, 목표를 $\boldsymbol{q}_1$이라 하면 보간점은 다음과 같이 표현할 수 있다.
\begin{equation}
\boldsymbol{q}(\alpha)=(1-\alpha)\boldsymbol{q}_0+\alpha\boldsymbol{q}_1,
\qquad 0\leq\alpha\leq1.
\end{equation}
보간 과정에서 틱당 관절 변화량을 제한하고, 로봇 입출력 단계의 상대 목표 클램프를 추가 적용한다. 측정 자세에서 시작하면 이전 동작이 목표에 충분히 도착하지 못한 경우에도 다음 궤적이 명령상의 가상 위치에서 시작하는 것을 줄일 수 있다.

\subsection{1차 미션: 지정 영역의 동적 슬롯 배치}

1차 미션의 완료 상태는 PLACE 호출 횟수만으로 결정하지 않는다. HOME에서 새로운 프레임을 받아 지정 영역 밖의 검출이 연속 5초 동안 없는지 확인한다. 같은 프레임을 반복 받거나 프레임이 오래된 경우에는 완료 시간을 계속 누적하지 않도록 구성하였다. 그러나 작업 영역 밖으로 탈락한 블록, 중심이 영역 안으로 들어온 블록, 색·형상 필터에서 누락된 블록은 이 판정만으로 구분되지 않는다. 최종 채점에서는 실제 다섯 블록의 배치와 경계 조건을 별도로 확인해야 한다.

\subsection{재시도와 제한시간의 실제 적용}
대상별 재시도 횟수 제한은 한 번의 순회에서 다른 대상을 시도하게 하는 데 사용된다. 현재 1차 미션 구현은 남은 모든 색이 보류되면 시도 기록을 보관하고 새 순회를 시작한다. 따라서 누적 재시도 횟수가 무한히 증가할 수 있으며, 1차 미션 실행기는 내부 FSM 시간 제한을 비활성화한다.

9월 8일 시험에서는 외부 프로세스 제한인 \texttt{timeout --signal=INT 180}을 사용하여 관찰 시간을 제한하였다. 이 명령은 180초에 종료 신호를 보내는 방식이며, 종료 시 그리퍼 개방과 홈 복귀가 추가로 시도되므로 모든 모터 동작이 그 시각에 즉시 정지함을 뜻하지 않는다. 대회 조건에 맞는 실행을 위해서는 미션 시간의 종료와 안전 정리 동작을 구분한 검증이 필요하다. 기존 설계 규칙의 틱 단위 시간 검사만으로 현재 실행 경로 전체의 제한시간을 보장한다고 기술하지 않는다.

\subsection{2차 미션: 접촉 기반 적재 구조}
2차 미션은 공통 파지·확인 흐름에 적재용 PLACE 전략을 연결하는 구조이다. 구현된 적재 프리미티브는 기록된 타워 접근 자세와 하강 키프레임을 사용하고, 하강 사이에 관절 부하의 기준값 대비 변화를 확인한다. 접촉이 감지되면 실행한 궤적에서 일부 되돌린 뒤 해제하며, 키프레임 끝까지 접촉이 없으면 경고를 남기고 해제한다.

설계 문서에는 블록 높이를 이용한 해제 높이 계산이 제시되어 있으나, 현재 적재 코드의 주 실행 방식은 기록된 관절 키프레임을 따라 하강하는 방식이다. 이를 최종 Task1의 동적 슬롯 IK와 동일한 구현으로 설명하지 않는다. 또한 현재 저장된 자세 파일에는 \texttt{home}만 존재하며, 타워 접근과 하강 키프레임 등 2차 미션에 필요한 자세는 추가 기록이 필요하다. 따라서 현재 기본 설정만으로 적재 실행 준비가 완료되었다고 볼 수 없다.

적재 상태가 5초 동안 유지되는지에 대한 실기 증거도 추가로 필요하다. 1차 미션의 ``외부 검출 없음 5초''는 대상 부재 확인 조건으로, 2차 미션의 ``적재 안정성 5초''와 전혀 다른 평가이다. 접촉 감지와 그리퍼 해제만으로 탑의 유지 성공을 판단하지 않는다.

\subsection{안전 처리와 실행 기록}
안전 처리는 관절 보간의 변화량 제한, 상대 목표 클램프, IK 게이트, 파지 확인, 장비 세션의 온도·관측 관리 등 여러 계층에 배치하였다. 정상적인 목표 명령이라도 실제 관절이 지연될 수 있으므로 하강과 접근의 도착 조건을 따로 둔다. 구성요소별 검사는 위험을 줄이는 장치이며 장비 전체에 대한 안전 인증이나 모든 충돌의 회피를 의미하지 않는다.

러너는 종료 시 그리퍼를 열고 홈으로 복귀하는 정리를 \texttt{finally}에서 시도하며 연결을 해제한다. 통신이나 장비 오류가 지속되는 경우 정리 동작이 실패할 수 있으므로 예외를 기록한다. 연결 해제 시 토크를 자동으로 끄지 않는 설정을 사용하며, 세션별 실제 종료 상태는 실험 기록에 남긴다. 모터 동작을 실행하지 않는 dry-run과 실기 시험 결과를 별도로 보관한다.

캘리브레이션 사진·관절값·후보 설정, 상태 전이와 단일 블록 시험의 단계별 기록은 날짜별 실험 디렉터리에 보관하였다. 실행 중 공유 상태와 관제 정보는 별도 런타임 경로로 분리한다. 보고서의 근거를 현재 기본값에만 연결하지 않고, 해당 시험에서 적용한 설정과 함께 연결하는 이유가 여기에 있다.
