\chapter{결론 및 향후 연구 방향}
\section{결론}
본 과제는 ACT·SmolVLA의 단일 블록 시연 학습과 ACT--CV/IK 하이브리드 시도를 거쳐 CV+IK 기반 이동·적재 시스템을 구현하였다. 시작 위치와 카메라 조건 변화에 따른 불안정성, 시연 재수집 부담을 고려하여 검출·좌표 변환·파지 확인·재시도를 단계별로 구성하였다.

1차 미션은 30회 중 28회가 180초 내 다섯 블록 배치를 완료하여 미션 성공률 93.3\%를 기록하였다. 재시도 포함 파지는 170회 중 148회(87.1\%) 성공하였다. 실패한 두 시행에서 관찰한 블록 밀림과 작업 반경 이탈은 재시도만으로 해결하기 어려운 문제로 남았다.

2차 미션은 계산한 자세에서 직접 해제하는 방식으로 5단 적재를 20회 시도하였다. 수행 중 최대 높이 기준으로 3단에는 20회, 4단에는 17회 도달했으나 5단에는 도달하지 못하였다. 따라서 다섯 블록의 적재와 5초 유지를 요구하는 전체 목표는 달성하지 못했으며, 최대 도달 높이와 종료 시 유지 상태를 구분한 후속 평가가 필요하다.

자동 수집 기능인 Task3은 첫 라운드에서 5개 에피소드·2{,}111프레임을 저장하였다. 본 과제의 기여는 기존 영상 처리·기구학 도구를 과제 조건에 맞게 통합하고, 관측과 센서 판정에 따른 실패 복구 및 실행 자료의 자동 기록을 연결한 데 있다. 이후에는 적재 안정성과 환경 변화에 대한 반복성을 보완하고, 수집 자료를 이용한 정책 재학습의 효과를 검증해야 한다.

\section{향후 연구 방향}
\subsection{미션 및 파지 집계와 시간 예산의 보완}
시행별 배치, 파지 후보·재시도와 소요 시간을 연결해 기록하여 최초 파지 성공률과 복구 비용을 구분할 계획이다. 블록 밀림과 작업 반경 이탈을 완료 판정에 반영하고, 한 대상에 시간이 집중되지 않도록 후보별 시간 상한과 대상 전환 시점을 보완해야 한다. 외부 제한시간, 내부 실행 예산과 종료 후 정리 시간도 구분하여 기록한다.

\subsection{적재 높이별 반복성과 안정성 검증}
\label{sec:stack-extension}
수행 중 최대 높이와 함께 종료 시 높이, 유지 시간과 무너짐 시점을 기록하고, 4단에서 5단으로 넘어갈 때의 정렬·해제 동작을 분석할 계획이다. 명목 블록 높이만으로 실제 타워 상태를 판단하기 어려우므로 접촉 기반 하강과 안착 확인을 보완하고, 현재의 직접 해제 방식과 같은 조건에서 비교하여 적재 안정성을 평가한다.

\subsection{자동 수집 자료의 확장과 정책 재학습}
\label{sec:dataset-extension}
다양한 배치와 접근 방향에서 시연을 수집하고, 센서로 정한 성공 라벨을 실제 안착 상태와 대조할 계획이다. 학습 목적에 따라 실패·복구 동작과 적층 정렬을 포함할 범위도 정해야 한다.

LeRobotDataset의 영상·상태·행동 및 작업 지시 형식에 맞춰 자료의 호환성을 확인한 뒤\cite{lerobot-dataset}, ACT와 SmolVLA를 재학습할 계획이다\cite{act,smolvla}. 수집량과 정책 성능을 각각 평가하고, 학습에 사용하지 않은 배치·관측 조건에서 수행 결과를 비교한다.

\subsection{LLM의 도구 호출을 이용한 작업 계획}
현재 FSM은 정해진 대상 선택과 상태 전이 규칙을 따른다. 이를 사용자의 작업 지시에 맞게 확장하기 위해, 기존 검출·좌표 변환·도달성 검사·파지·배치·기록 기능을 도구로 제공하고 대규모 언어모델(LLM)이 필요한 기능을 선택·호출하는 구성을 검토한다. LLM은 상위 작업 순서와 도구 인자를 결정하며 실제 동작은 기존 CV+IK 제어기가 생성하도록 한다.

예를 들어 특정 색상의 블록을 먼저 옮기라는 지시가 주어지면 검출 결과에서 대상을 선택하고 파지·배치 도구를 호출한다. 각 도구는 성공 여부와 실패 이유를 반환하며, LLM은 이를 바탕으로 재시도나 다른 대상 선택을 결정한다. 도달성 검사, 관절 명령 제한, 파지 확인과 시간 예산은 도구 실행 계층에서 강제하여, 파지가 확인되지 않은 운반 명령은 실행하지 않도록 설계한다.

이 구상은 아직 구현·검증하지 않은 후속 연구이다. 도구 호출 실패와 불명확한 지시의 처리 기준을 정하고, 고정된 FSM과 동일한 작업 조건에서 미션 완료율·수행 시간·도구 선택의 적절성·실패 후 복구 결과를 비교할 계획이다.
