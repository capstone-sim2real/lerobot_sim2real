\chapter{결론 및 향후 연구 방향}
\section{결론}
본 과제는 ACT·SmolVLA의 단일 블록 시연 학습과 하이브리드 시도를 거쳐 CV+IK 기반 이동·적재 시스템을 구현하였다. 시작 위치와 카메라 조건 변화에 따른 불안정성, 시연 재수집 부담을 고려하여 검출·좌표 변환·파지 확인·재시도를 단계별로 구성하고 실행 자료를 저장하였다.

1차 미션은 30회 중 28회가 180초 내 다섯 블록 배치를 완료하여 전체 미션 성공률 93.3\%를 기록하였다. 재시도 포함 파지는 170회 중 148회(87.1\%) 성공하였다. 최종 아홉 점 좌표 변환의 적합 RMS는 5.15\,mm, 최대 LOO 오차는 13.53\,mm였다.

적재는 계산한 자세에서 직접 해제하는 방식으로 수행하였다. 5단을 목표로 20회 시도한 결과, 수행 중 최대 높이 기준으로 3단에는 20회, 4단에는 17회 도달했고 5단에는 도달하지 못하였다. 재시도 포함 파지는 113회 중 94회(83.2\%) 성공하였다. 높이별 도달 횟수는 종료 시 높이나 해제 후 5초 유지 성공률을 뜻하지 않는다.

Task3은 첫 라운드에서 5에피소드·2{,}111프레임을 저장하여 정책 학습에 활용할 기반을 마련하였다. 정책 재학습은 후속 과제로 남았으며, 구현한 기능을 도구로 제공하여 대규모 언어모델(LLM)이 작업에 맞게 선택·조합하는 확장도 검토한다.

\section{향후 연구 방향}
\subsection{미션 및 파지 집계와 시간 예산의 보완}
시행별 배치, 파지 후보·재시도와 소요 시간을 연결해 기록하여 최초 파지 성공률과 복구 비용을 구분할 계획이다. 실패한 두 미션에서 관찰한 블록 밀림과 작업 반경 이탈을 완료 판정에 반영하고, 후보별 시간 상한과 대상 전환 시점을 보완해야 한다. 외부 제한시간, 내부 실행 예산과 종료 후 정리 시간도 구분하여 기록한다.

\subsection{적재 높이별 반복성과 안정성 검증}
\label{sec:stack-extension}
수행 중 최대 높이와 함께 종료 시 높이, 유지 시간과 무너짐 시점을 기록하고, 4단에서 5단으로 넘어갈 때의 정렬·해제 동작을 분석할 계획이다. 실제 타워 높이와 관측 오차를 고려하여 배치 자세를 보완하고, 직접 해제와 접촉 기반 하강을 같은 조건에서 비교하여 안착·유지에 적합한 방식을 확인한다.

\subsection{자동 수집 자료의 확장과 정책 재학습}
\label{sec:dataset-extension}
다양한 배치와 접근 방향에서 시연을 수집하고, 센서로 정한 성공 라벨을 실제 안착 상태와 대조할 계획이다. 학습 목적에 따라 실패·복구 동작과 적층 정렬을 포함할 범위도 정해야 한다.

LeRobotDataset의 영상·상태·행동 및 작업 지시 구성을 따라\cite{lerobot-dataset}, 자료의 호환성과 라벨 품질을 확인한 뒤 ACT와 SmolVLA를 재학습할 계획이다\cite{smolvla}. 수집량과 정책 성능을 각각 평가하고, 학습에 사용하지 않은 배치·관측 조건에서 수행 결과를 비교한다.

\subsection{LLM의 도구 호출을 이용한 작업 계획}
기존에 구현한 블록 검출, 좌표 변환, 도달성 검사, 파지·운반·배치, 결과 확인과 에피소드 저장 기능을 입력과 반환값이 명확한 도구(tool)로 분리할 계획이다. LLM은 사용자의 작업 지시와 관측 결과를 바탕으로 필요한 도구와 인자를 선택하고, 반환된 실행 결과에 따라 다음 동작을 결정하도록 구성한다. 이때 LLM은 상위 작업 계획을 담당하고 실제 동작 생성에는 기존 CV+IK 제어를 사용한다.

예를 들어 특정 색상의 블록을 먼저 옮기라는 지시가 주어지면 검출 도구의 결과에서 대상을 선택하고 파지·배치 도구를 호출한다. 파지 실패나 도달 불가가 반환되면 재시도 또는 다른 대상 선택으로 계획을 수정한다. 각 도구가 성공 여부와 실패 이유를 반환하도록 하여, 언어 지시의 해석과 실행 중 상황 변화에 대한 대응을 함께 다룰 수 있도록 할 계획이다.

도달성 검사, 관절 명령 제한, 파지 확인과 실행 시간 예산은 도구를 실행하는 제어기에서 강제한다. LLM이 운반 도구를 선택하더라도 파지가 확인되지 않으면 실행하지 않도록 하며, 도구 호출에 실패하거나 지시가 불명확할 때의 처리도 정의해야 한다. 후속 평가에서는 고정된 상태 흐름과 같은 작업 조건을 사용하여 미션 완료율, 수행 시간, 도구 선택의 적절성과 실패 후 복구 결과를 비교할 계획이다. 이 구성은 아직 구현·검증하지 않은 후속 연구이며 본 보고서의 실험 결과에는 포함하지 않았다.
