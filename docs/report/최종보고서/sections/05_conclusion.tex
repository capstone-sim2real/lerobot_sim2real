\chapter{결론 및 향후 연구 방향}
\section{결론}
본 과제는 SO-101의 블록 이동과 적재를 해결하기 위해 ACT와 SmolVLA 기반 모방학습으로 시작하였다. ACT 데이터를 131개 에피소드까지 확대하고 추론 설정과 파지·배치의 역할 분담을 조정했으나, 관측 조건 변화에 따른 동작 변동과 실패 원인 진단의 어려움이 남았다. 팀은 시연장 운용과 개발 일정을 고려하여, 인식과 제어의 중간 결과를 확인하고 조정할 수 있는 CV+IK 구조로 전환하였다.

최종 시스템은 블록 검출과 평면 좌표 변환, IK 계획, 위치·부하 기반 파지 확인과 재시도를 하나의 상태 흐름으로 연결하였다. 초기 실기의 빈손 파지와 좌표 편차, 시간 소모를 로그와 영상으로 구분한 뒤 캘리브레이션과 파지 방향·복구 동작을 보완하였다. 개선 후 1차 미션은 팀 집계 기준 30회 중 28회가 180초 내 다섯 블록 배치를 완료하여 전체 미션 성공률 93.3\%를 기록하였다. 최신 아홉 점 적합은 RMS 5.15\,mm와 최대 LOO 13.53\,mm로 확인되었으나 개발 기준에는 미달하였다.

최종 적재는 계산한 자세에서 직접 해제하는 방식으로 수행하였다. 5단을 목표로 20회 시도했으며 수행 중 최대 높이 기준으로 3단에는 20회, 4단에는 17회 도달했고 5단에는 도달하지 못하였다. 재시도를 포함한 파지는 113회 중 94회(83.2\%) 성공하였다. 높이별 도달 횟수는 종료 시 높이나 해제 후 5초 유지 성공률을 뜻하지 않는다. 초기 수동 시연 수집의 부담을 줄이는 확장으로 Task3도 구현하여 첫 라운드에서 5에피소드·2{,}111프레임을 저장하였다. 이 데이터로 정책을 재학습하지는 못했다.

본 과제의 성과는 실기에서 드러난 제약에 따라 접근법을 변경하고, 실패를 단계별로 진단할 수 있는 구조를 통해 반복 과제 수행과 실행 데이터 수집으로 확장한 것이다. 모방학습과 CV+IK는 동일 조건의 비교 실험을 수행하지 않아 일반적인 성능 우열을 주장하지 않는다. 최신 집계의 조건별 분석과 적재 반복성, 환경 변경에 대한 검증은 남은 과제이다.

\section{향후 연구 방향}
\subsection{미션 및 파지 집계와 시간 예산의 보완}
전체 미션 30회 중 28회 완료와 재시도 포함 파지 217회 중 148회 성공(68.2\%)은 서로 다른 단위의 지표이다. 시행별 초기 배치, 대상 선택·후보 재시도·재선택을 구분한 기록을 연결하여 최초 파지율과 재시도 비용을 계산할 계획이다. 현재 합계만으로 대상별 최초 성공률이나 복구 효과를 계산하지 않았다.

실패한 두 미션에서는 파지 동작이 블록을 작업 반경 밖으로 밀어낸 뒤 시간 초과로 이어졌다. 밀림과 이탈을 감지하고, 도달 범위 밖의 블록이 검출에서 사라졌다는 이유만으로 완료하지 않도록 판정을 보완해야 한다. 종료 시 블록 수와 시행별 소요 시간을 기록하고 위치·방향·환경별 반복 시험으로 범위를 확장할 계획이다. 내부 시간 예산과 외부 180초 종료, 종료 후 정리 동작을 구분하며, 한 대상에 시간을 과도하게 쓰지 않도록 후보별 시간 상한과 대상 전환 시점을 검토한다.

\subsection{적재 높이별 반복성과 안정성 검증}
\label{sec:stack-extension}
현재 5단 목표 20회에서는 수행 중 4단에 17회 도달했지만 5단에는 도달하지 못했다. 다음 시험은 최대 높이와 함께 종료 시 높이·유지 시간을 기록해야 한다. 4단에서 5단으로 넘어갈 때의 정렬, 해제와 무너짐을 분석하고, 파지 성공 94/113회와 적층 상태의 변화를 같은 시행에서 연결할 계획이다.

현재 층별 계획의 명목 높이와 배치 횟수는 실제 타워 상태의 측정값이 아니다. 평면 변환도 블록 한 개의 윗면을 기준으로 하므로 적재 높이가 바뀌면 관측 오차를 검토해야 한다. 접촉 기반 배치라는 설계 목표, 현재 직접 해제 방식과 실제 안정성 검증을 구분하여 후속 제어를 설계한다. ArUco 위치 추정과 손목 게이트는 실험용 코드를 정리하고 각각의 효과를 같은 조건에서 검증해야 한다.

\subsection{자동 수집 자료의 확장과 정책 재학습}
\label{sec:dataset-extension}
Task3은 CV+IK 실행의 영상·관절 상태·전달 명령을 기록하고, 센서 파지 확인과 배치·home 복귀를 마친 사이클을 저장한다. 첫 라운드 5에피소드는 자동 수집의 구현과 파일 구조 확인에 해당한다. 이 자료로 ACT를 재학습하거나 성능을 비교하는 단계는 아직 수행하지 못하였다.

다양한 배치와 접근 방향을 고르게 수집하고, 센서·제어 흐름으로 정한 성공 라벨을 실제 안착 상태와 대조해야 한다. 최초 파지 실패를 폐기하는 현재 구조에는 실패·복구 시연과 적층 정렬이 포함되지 않는다. 학습 범위를 파지로 한정할 경우에는 전체 사이클의 구간 분리 기준도 필요하다.

LeRobotDataset의 영상·상태·행동 및 작업 지시 구성을 따라\cite{lerobot-dataset}, ACT와 SmolVLA에 사용할 데이터의 호환성과 라벨 품질을 확인할 계획이다\cite{smolvla}. 수집량 증가와 정책 성능 개선은 각각 별도 평가 대상으로 둔다.
