\chapter{결론 및 향후 연구 방향}
\section{결론}
본 과제는 실제 장비에서 관측한 인식 혼동, 좌표 편차와 빈손 파지에 대응하여 SO-101의 CV+IK 기반 블록 이동 시스템을 구현하였다. 팀은 색상과 형상에 따른 대상 선택, 중립 손목 방향과 대체 파지 후보, 위치/부하 확인, 재시도 및 슬롯 배치를 하나의 상태 흐름으로 연결하였다. 카메라 웹 뷰어와 캘리브레이션 기록 도구를 통해 영상, 대응점과 관절 상태를 함께 확인하고, 실행 로그로 실패 단계를 추적할 수 있도록 구성하였다.

외부 180초 제한의 전체 미션 시험에서는 파지 후보 14회의 실행 시작, HELD 4회, EMPTY 9회와 판정 전 중단 1회를 기록하였다. 노란 블록은 같은 PICK 안의 세 번째 후보에서, 빨간 블록은 재선택 후 파지가 확인되어 후속 운반과 슬롯 해제로 진행하였다. 별도 단일 블록 시험에서는 파지와 운반 성공, 위치 변경 후 빈손 파지를 관찰하였다. 이 결과는 목표 자세의 계산에 더해 접촉 확인과 복구 흐름을 연결한 설계가 실제 실행에서 사용되었음을 보여준다.

전체 미션은 네 번의 슬롯 해제 후 마지막 블록이 남아 미완료였으며, 해제 수를 인정 블록 수로 환산하지 않았다. 빨간 블록의 첫 PICK에만 51.5초가 소요되어, 실패 복구와 함께 대상별 시간 예산을 관리할 필요가 확인되었다. 좌표 정합은 RMS 8.18\,mm, 최대 LOO 26.64\,mm로 개발 목표에 미달하였다. 최종 방식의 동일 조건 반복 성공률과 ACT 대비 성능 차이는 측정하지 못했으며, 적재는 PLACE 전략과 접촉 감지 구현 이후 자세 등록과 통합 실기가 남아 있다. 후속 작업은 블록 이동의 반복 평가와 시간 관리, 적재 높이별 검증 순서로 진행한다.

\section{향후 연구 방향}
\subsection{동일 조건 반복 평가와 시간 예산 개선}
우선 한 초기 배치를 사진으로 고정하고 코드, 실행 설정과 캘리브레이션을 유지한 상태에서 전체 미션을 3회 반복할 계획이다. 각 시행에 대해 사람이 판정한 인정 블록 수, 시스템 완료 상태, 제한시간 종료와 실제 정리 동작 시간을 따로 기록한다. 파지 영상과 센서 판정을 연결하고 첫 후보, PICK 내부 재시도 및 대상 재선택을 구분한다. 이 소규모 시험은 고정 배치의 반복성 평가이며, 무작위 배치의 일반화 평가는 별도로 수행한다.

현재의 실패 기록을 바탕으로 후보별 시간 상한과 다음 블록으로의 전환 시점을 우선 검토한다. 성능 측정 중에는 설정을 변경하지 않고, 이후 같은 배치에서 재시도 정책을 변경한 결과를 비교한다. 실제 턱과 블록의 상대 위치 측정, 파지 직전 영상 보정, 검출 누락과 물리적인 완료 조건의 차이도 후속 개선 대상으로 둔다.

\subsection{적재 높이별 동작 개선과 실기 평가}
\label{sec:stack-extension}
적재는 타워 접근과 하강 자세를 등록한 뒤 높이별 도달성, 관절 한계와 그리퍼 개방 공간부터 확인한다. 수직 접근이 어려운 높이에서는 기울인 접근 방향을 후보로 검토하되, 아래 블록과의 간섭 및 해제 후 안정성을 함께 평가한다. 접촉 감지와 되돌림 후 해제가 타워를 흔드는지 2단과 3단에서 확인한 뒤 다섯 블록과 5초 유지 조건으로 확대한다. 현재는 낮은 단수의 실기 성공도 확인되지 않았으며, 각 단계의 시도 횟수와 실패 단계, 유지시간을 기록할 계획이다.

평면 변환은 블록 한 개의 윗면을 기준으로 하므로 타워가 높아졌을 때 같은 변환을 그대로 적용할 수 없다. 초기에는 고정한 타워 위치와 기록 자세를 사용하고, 높이 변화에 따른 관측 오차와 적재물 재선택 문제를 별도로 평가한다.

\subsection{규칙 기반 실행의 학습 데이터 활용}
\label{sec:dataset-extension}
미션의 반복 수행과 결과 판정이 안정화되면 CV+IK 실행 중 영상, 관절 상태와 전달 명령을 같은 시간 기준으로 기록하는 확장을 검토한다. 초기에는 사람이 블록을 재배치하고, 단일 블록 선택부터 배치 후 재관측까지를 한 에피소드로 구성한다. 내부 재시도, 실패, 시간 초과와 사람의 확인 결과를 함께 저장하며, 현재의 사진 및 텍스트 기록에 동기화와 에피소드 구성 기능을 추가해야 한다.

LeRobotDataset의 영상, 상태, 행동과 에피소드 구성을 참고하되 사용할 버전과의 호환성을 확인한다\cite{lerobot-dataset}. 모방학습이나 SmolVLA에 활용하려면 측정 관절값과 전달 명령을 구분하고 작업 지시 및 센서 라벨의 신뢰도를 검토해야 한다\cite{smolvla}. 강화학습용으로는 다음 관측, 보상과 종료 조건을 추가 정의한다. 파지 판정과 배치 성공은 별도 라벨로 관리하며, 유효 에피소드 수와 기록 누락, 사람의 작업시간으로 수집 방식을 평가할 계획이다. 동기화 데이터셋 생성과 무인 반복 수집은 아직 구현하지 않았다.
