\chapter{서론}
\section{연구 배경}
본 과제의 목표는 SO-ARM101 로봇팔로 다섯 블록을 제한시간 안에 지정 영역으로 옮기고, 후속 미션에서 적재하는 것이다. 이하에서는 SO-ARM101을 SO-101로 표기한다. 초기에는 이동형 로봇의 물체 수집을 검토했으나 과제 규격이 바뀌면서 SO-101 블록 조작으로 범위를 변경하였다. 개발 환경에서 개별 동작을 성공시키는 것과 함께, 장비를 실제 시연장으로 옮긴 뒤에도 여러 블록을 반복 처리할 수 있어야 했다.

초기 접근은 사람이 리더암으로 단일 블록을 집어 중앙 목표 지점으로 옮기는 동작을 시연하고, 이를 ACT와 SmolVLA로 학습하는 것이었다. 작업 영역 전체에서 블록의 시작 위치를 무작위로 바꾸어 약 100개 에피소드를 수집했지만 수행 성공률은 약 2--10\%에 머물렀다. 시작 위치를 특정 지점으로 한정한 51개 에피소드로 학습했을 때는 50회 중 29회 성공하였다. 이후 시작 위치를 다시 전 영역으로 넓혀 약 120개 에피소드를 수집·학습하자 성공률은 약 10--20\%로 낮아졌다. 이 세 단계는 모두 단일 블록 이동 실험이며, 블록 수가 아니라 시작 위치의 범위를 바꾼 과정이다.

단일 블록의 파지와 이동도 안정적이지 않자, 팀은 학습 정책의 역할을 줄이고 컴퓨터 비전·역기구학(CV+IK)과 결합하는 하이브리드 방식을 시도하였다. 팀 내부 비교에서 SmolVLA보다 추론이 빠르고 성공률이 일관되게 높았던 ACT를 선택했으나, 추가 튜닝으로도 약 60\%를 넘는 안정적인 수행을 확보하기 어려웠다. 카메라 위치를 조금 바꾼 뒤에는 시연부터 다시 수집해야 했고, 100개 이상의 에피소드를 사람이 다시 녹화하는 부담이 컸다. 이러한 상태로는 실제 시연장으로 장비를 옮긴 뒤의 수행을 기대하기 어려웠다.

여기서 개발 순서를 바꾸는 아이디어가 나왔다. 먼저 크기·색상이 정해진 블록과 고정 평면에 맞는 CV+IK 실행기를 만들고, 그 실행을 기록해 모방학습의 시연 자료로 사용하는 것이다. 이 구상에 따라 검출·좌표·IK·파지 확인·재시도를 분리해 관찰하고 보정할 수 있는 제어 경로를 구축하였다. 이후 반복 미션 수행을 개선하고 Task3 자동 수집을 구현하였다. 수집 자료로 정책을 다시 학습하는 단계는 후속 과제로 남았다(그림~\ref{fig:research-path}).

\section{초기 접근의 한계와 설계 요구}
첫째, 특정 시작 위치에서 얻은 결과를 작업 영역 전체의 수행으로 확장할 수 있어야 했다. 위치를 한정한 단일 블록 실험의 성공률은 58\%였지만, 시작 위치를 다시 넓힌 실험에서는 낮아졌다. 이 결과는 데이터 수만 늘리는 것과 다양한 배치에서 안정적으로 동작하는 것이 같지 않음을 보여주었다. 각 단계의 학습 조건도 달랐으므로 위치 범위만의 인과적 효과로 해석하지는 않았다.

둘째, 환경 변화에 대응하면서 수동 시연 수집의 반복 부담을 줄여야 했다. 카메라 위치 변경 뒤 100개 이상의 시연을 다시 녹화하는 대신, 조정 가능한 실행기를 이용해 학습 자료를 수집하는 경로를 구상하였다. CV+IK에서도 카메라 고정·재캘리브레이션과 조명에 따른 검출 조정은 필요하지만, 검출 중심·로봇 좌표·목표 자세·센서 판정을 확인하며 수정할 단계를 좁힐 수 있도록 하였다.

셋째, 개별 파지 실패를 전체 미션의 중단으로 이어지지 않게 해야 했다. 제한시간 내 여러 블록을 처리하려면 파지를 확인한 뒤 운반하고, 실패 시 재시도하거나 대상을 다시 선택해야 한다. 최종 제어 흐름은 이 판단을 명시적으로 관리하며, 모방학습 실험에서 사용한 모터 통신과 장비 운용 경험도 재사용하였다.

이후 개발에서는 색상이 비슷한 테이프의 오검출, 영상 좌표와 실제 파지 위치의 편차, 빈손 파지와 재시도 시간 비용을 다루었다. 3장은 이에 대응한 최종 구조를 설명하고, 4장은 개선 후 수행 결과와 초기 실패의 근거를 연결한다.

\section{연구 목표}
\subsection{미션 규격과 성공 조건}
블록은 $40\times40\times20\,\mathrm{mm}$ 크기이며, 서로 다른 색의 블록 다섯 개를 사용한다. 미션 시작 시 각 블록은 넓은 면을 바닥에 둔 채 지정 영역 밖에 놓인다. 블록끼리 맞닿을 수는 있지만 위아래로 겹치지는 않는다. 두 미션은 블록을 다시 배치한 뒤 각각 수행한다. 목표와 평가 조건은 표~\ref{tab:mission}과 같다.

지정 영역은 로봇 베이스에서 약 25\,cm 떨어진 곳에 두며, 제어할 때는 네 꼭짓점을 로봇 베이스 좌표계에 등록한다.

신경망은 최대 하나까지 사용할 수 있으나 필수는 아니다. 최종 CV+IK 시스템은 신경망 없이 영상 처리와 기구학 계산으로 동작한다.

\subsection{세부 연구 목표}
영상에서 지정 영역 밖의 블록을 골라 로봇 좌표로 변환하고, 관절 한계와 그리퍼 방향을 고려한 접근·파지·이동 자세를 생성한다. 파지 확인과 재시도를 포함한 상태 흐름으로 블록을 반복 처리하며, 단계별 자료를 기록해 실패 지점을 추적한다. 적재 미션으로 동작을 확장하고, CV+IK의 실행 자료를 학습 데이터로 저장하여 향후 모방학습을 다시 시도할 기반을 마련한다.

평가는 초기 진단 시험, 캘리브레이션 재수집, 개선 후 반복 미션과 적재 시험, 자동 데이터 수집으로 나누었다. 개선 후 1차 미션은 30회 중 28회(93.3\%) 완료하였다. 2차 미션은 5단을 목표로 20회 시도했으며 수행 중 3단에는 20회, 4단에는 17회 도달했다. 5단 도달과 종료 후 유지라는 전체 규격은 달성하지 못하였다. Task3은 성공 실행의 자동 기록을 구현하고 첫 라운드 5개 에피소드를 저장하였다. 실험 조건과 집계의 적용 범위는 4장에서 구분한다.
