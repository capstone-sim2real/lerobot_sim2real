\chapter*{초록}
\thispagestyle{plain}
본 과제는 SO-ARM101 로봇팔로 다섯 블록을 180초 이내 지정 영역에 배치하고, 후속 미션에서 적재 후 5초간 유지하는 시스템을 목표로 하였다. 초기 ACT와 SmolVLA 실험을 거쳐 고정 카메라의 고전 컴퓨터 비전, 평면 좌표 변환과 역기구학을 결합한 제어 경로를 구현하였다. 팀은 색상과 형상을 이용한 대상 선택, 중립 손목 방향에 따른 파지 후보, 위치와 부하를 이용한 파지 확인, 재시도 및 동적 슬롯 배치를 유한상태기계로 연결하였다.

외부 180초 제한 시험에서 파지 후보 14회의 실행 시작이 기록되었다. 센서는 4회를 파지 상태, 9회를 빈손 상태로 판정하였고, 나머지 1회는 결과 판정 전에 중단되었다. 네 번의 슬롯 해제 동작을 수행했으나 마지막 블록이 영역 밖에 남아 전체 미션을 완료하지 못하였다. 해제 동작 수를 인정 블록 수로 환산하지 않았으며, 최종 방식의 반복 성공률은 측정하지 않았다. 별도의 단일 블록 시험에서는 파지와 운반 성공, 위치 변경 후 빈손 파지를 관찰하였다.

아홉 점 캘리브레이션의 적합 RMS는 8.18\,mm, 최대 LOO 오차는 26.64\,mm로 개발 목표에 미달하였다. 실행 기록에서는 재시도 후 파지 판정을 얻은 사례와, 한 블록의 첫 PICK에 51.5초가 소요된 사례를 함께 확인하였다. 이는 모델상의 도달성에 더해 실제 파지 상태와 재시도 시간 비용을 평가할 필요가 있음을 보여준다. 적재는 배치 전략과 접촉 감지의 구현 단계이며, 필요한 자세 등록과 통합 실기 검증이 남아 있다. 본 과제의 성과는 블록 이동 제어의 통합 구현과 단계별 실패 분석이며, 전체 미션의 반복 신뢰도와 적재 성능 확보는 후속 과제이다.
