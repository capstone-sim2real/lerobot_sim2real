## 다시 빌드하기

호스트에 Podman이 필요하다. 다음 명령은 이 디렉터리만 쓰기 가능하게 컨테이너에 연결한다.

```bash
bash docs/report/최종보고서/build.sh
```

최초 실행은 Ubuntu 24.04 기반 로컬 이미지 `localhost/so101-report-tex:ubuntu24.04`를 만들며 네트워크가 필요하다. 이후에는 해당 이미지의 pdfLaTeX·BibTeX·latexmk로 컴파일한다. 호스트 LaTeX 설치는 필요 없다. `build/`에 중간 파일을 만들고 완성 PDF를 이 디렉터리에 복사한다. `Containerfile`을 변경하면 이미지를 직접 다시 빌드해야 한다.

```bash
podman build -t localhost/so101-report-tex:ubuntu24.04 -f docs/report/최종보고서/Containerfile docs/report/최종보고서
```

컨테이너의 FFmpeg는 원본 HEVC 시연 영상에서 정지 프레임을 추출할 때 사용했다. PDF 재빌드에는 원본 영상이 필요 없으며, 포함된 `figures/` 파일이면 된다. `review/`는 렌더링 검토용이며 `build/`와 함께 Git 제외 대상이다.

## 수정 시 지킬 구분

ACT의 29/50회(58%)는 사용자가 제공한 튜닝 후 단일 블록 이동 집계다. 최종 CV+IK의 전체 미션 성공률로 바꾸지 않는다. 9월 2일 시연과 9월 8일의 실패·센서 기록은 서로 다른 조건의 사례로 다룬다. 적재 전략 구현과 다섯 블록 적재 후 5초 유지의 실기 검증도 구분한다.

제출 전에는 `SOURCES.md`의 미확인 항목을 검토하고, 새 근거가 확보된 내용만 본문에 반영한다. 본문과 별개인 시연 계획서/구글폼 제출은 이 작업에서 수행하지 않았다.

## 보고서 브랜치의 기준

이 보고서 브랜치는 `main`의 `37dd489`에서 분기했다. 본문이 설명하는 구현과 실험의 기준은 `SOURCES.md`에 명시한 `1fd914b`이며, 해당 기능 브랜치의 코드 변경을 이 보고서 커밋에 포함하지 않았다. 원본 대화·자문의견서·참고 자료 및 실험 아카이브 경로는 작성 당시 원본 체크아웃 기준이다. PDF 재빌드에 필요한 본문·클래스·그림·CSV는 이 디렉터리에 포함되어 있다.

동료 초안과의 통합에서는 설계 변경 경위를 보강하고, 캘리브레이션 5점→9점→15점→9점 이력을 추가했다. 초기 5점과 확장 9점의 RMS는 사용자 실측값 20.11mm와 13.46mm를 반영했으며, 적재 실기는 미수행으로 명시했다.

본문 전반의 편집용 출처 설명과 반복적인 확인 지시를 정리하고, 실험 방법·수행 결과·분석 중심으로 개정했다. 추가 실험 계획은 5장에 모았으며, 출처 관리와 제출 전 확인 목록은 `SOURCES.md`에서 관리한다.

박사과정 연구생 피드백에 관한 팀 대화를 반영하여, 관찰한 문제와 설계 변경의 관계를 보강했다. 연구 방향의 변화, FSM 전체 흐름, PICK 내부의 후보 시도와 센서 판정을 그림으로 정리했다.

후속 외부 검토에 따라 초록과 실기 결과 요약을 추가하고, 9월 8일 로그의 파지 후보 14회, 센서 HELD 4회/EMPTY 9회/판정 전 중단 1회와 슬롯 해제 4회를 집계했다. 상태별 시간과 캘리브레이션 잔차 방향을 원기록에서 재현하고, 사진의 관심 영역을 확대했다. 기존 실측값은 유지했으며 센서 판정 수를 물리적인 성공률로 환산하지 않았다.

5장은 전체 미션 반복 평가와 적재 실기를 우선하도록 정리하고, 학습 데이터 수집 계획을 두 문단으로 압축했다. 새로운 하드웨어 시험은 수행하지 않았다. `evaluation/`의 같은 초기 배치 3회 계획과 CSV는 향후 기록용이며, 새 결과가 없는 상태로 제출 PDF에 빈 성능표를 넣지 않았다.

9월 11일 사용자가 제공한 최신 역할 분담으로 표 3.6을 갱신했다. 윤민석의 비전/미션 제어와 포스터, 이동근의 관제/캘리브레이션 도구와 실행 환경, 김주환의 접근법 분석/평가 체계와 기술 문서/발표 자료 작업을 항목형으로 반영했다. 상세 역할 표는 본문 21쪽에 있다.

추가 회의록의 설계 판단 중심 조언을 적용하여 전체 FSM을 개별 모듈 설명보다 앞에 배치했다. 동일 대응점 P4의 접촉/팔 후퇴 사진과 좌표를 추가하고, 대체 후보와 재선택의 효과 및 시간 비용을 결과와 연결했다. 배경의 중복 설명을 줄이고 결론을 통합 구현, 실행 결과, 남은 검증 순서로 정리했다. 총 42쪽이며 표 3.6, 표 4.2와 기존 실측값은 유지했다. 수정 전 상태는 `b7a1a6a`에 커밋되어 있으며 이번 개정은 그 이후의 작업 내용이다.

제출 문체 정리에서는 본문 날짜를 실험명과 개발 단계로 바꾸고, 커밋/실행 ID/저장소 파일명은 `SOURCES.md`에서 관리하도록 정리했다. 코드 내부 이름은 기능 설명으로 풀어 썼으며, 표지와 참고 문헌의 날짜는 월 단위로 통일했다. 실험 조건과 수치, 역할 분담의 의미는 유지했다.
