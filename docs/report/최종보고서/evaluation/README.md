# 제출 전 짧은 반복 시험

이 문서는 아직 수행하지 않은 추가 시험의 기록 양식이다. 결과를 미리 채우지 않는다. 본문에는 기존 기록만 반영했으며, 새 시험 결과를 확보한 뒤 표와 초록을 갱신한다.

## 시험 범위

한 초기 배치 `A`에서 전체 미션을 3회 반복한다. 다섯 블록의 위치와 방향을 시작 사진으로 기록하고 매 시행 같은 배치를 재현한다. 각 시행은 180초 제한이며, 재배치와 사전 준비 시간은 별도다. 세 번은 동일 배치의 반복 관찰이며 무작위 환경의 일반 성공률 평가로 확대하지 않는다.

기존 운용 절차에 따라 장치 식별, 카메라 고정과 드리프트, 캘리브레이션 상태, 경로 dry-run을 먼저 확인한다. 현재 장비에 맞는 기존 실행 절차를 사용하며, 이 문서는 하드웨어를 실행하거나 설정을 변경하는 스크립트가 아니다. 충돌, 과열 또는 비정상 동작으로 중단한 시행도 보관한다.

## 조건 고정

시험 시작 전 코드 커밋과 미커밋 변경, 실행 명령, 설정 파일, 캘리브레이션/자세 파일을 저장한다. 코드 버전만 같아도 설정이 다르면 같은 조건으로 묶지 않는다. 세 번 사이에 카메라를 움직이거나 파지/슬롯 보정, 주파수, 센서 임계값을 조정하지 않는다. 변경이 필요하면 새 조건 ID로 분리한다.

모션 명령 주파수와 카메라 주파수는 별도로 기록한다. 카메라 모델, 영상 해상도와 설치 치수를 실제 장비에서 확인하고, 확인하지 못한 값은 `unknown`으로 남긴다. 실행한 장비의 패키지 목록과 LeRobot 서브모듈 커밋도 보관한다. 보고서 워크트리의 `main` 기반 코드를 실기 코드로 오인하지 않도록 실제 운용 체크아웃의 정보를 기록한다.

## 기록 순서

1. 설정과 초기 배치를 저장하고 전체 작업 공간과 목표 경계를 볼 수 있게 영상을 시작한다. 기존 영상에 턱이 가려진다면 가능한 관찰 위치에서 보조 영상을 함께 촬영한다.
2. 외부 제한의 시작, 미션 시작 로그, 제한시간 도달, 마지막 동작/정리 종료 시각을 구분한다. 외부 제한이 초기화를 포함하는지 기록한다. 보고서의 과거 실행은 초기화 시간이 외부 180초에 포함됐으므로 새 시험과 비교할 때 이 차이를 남긴다.
3. 각 후보의 센서 결과와 대응하는 영상 구간을 연결한다. 대상별 첫 후보, 같은 PICK 안의 추가 후보, SELECT로 돌아간 재선택을 따로 기록한다.
4. 제한시간 시점의 장면에서 사람이 인정 조건으로 블록 수를 판정한다. 팔을 치운 뒤 촬영한 사진만으로 제한시간 시점의 결과를 대체하지 않는다. 종료 처리로 블록이 움직였으면 그 사실을 기록한다.
5. 시스템의 `DONE` 여부, 사람이 판정한 미션 성공, 중단 사유를 각각 입력한다. 가림으로 판정할 수 없으면 `unknown`으로 남기고 성공 또는 실패로 임의 변환하지 않는다.

## 판정과 집계

- 미션: 실제 다섯 블록이 제한시간 안에 인정 조건을 만족했는지 판정한다. 1차 미션은 경계 20mm 이내 걸침, 세로 세움과 일부 겹침을 허용하고 적재는 인정하지 않는다. 경계는 블록 중심만으로 판정하지 않는다.
- 파지: 센서 `HELD/EMPTY`와 영상상 `held/empty/unknown`을 별도 기록한다. 비교 가능한 영상만으로 두 판정의 일치/불일치를 집계하고, 가림과 판정 전 중단 수를 함께 제시한다. 같은 후보의 PICK와 VERIFY를 독립된 파지 시도로 중복 집계하지 않는다.
- 재시도: 첫 후보로 얻은 파지, 추가 후보 뒤 얻은 파지, 재선택 뒤 얻은 파지를 구분한다. 재시도 사용 전후의 인과적 효과는 별도 대조 시험 없이는 주장하지 않는다.
- 시간: 성공 시행만 평균내어 전체 성능처럼 제시하지 않는다. 모든 시행의 성공 여부, 종료 시 인정 블록 수, 경과시간과 중단 사유를 함께 표시한다.
- 조건: 기존 9월 8일 30Hz 시험과 새 시험을 같은 조건의 반복으로 합치지 않는다. 추가 시험이 없으면 빈 결과표를 제출 PDF에 넣지 않는다.

## 사용할 파일

- `runs.csv`: 시행별 조건과 최종 결과. 헤더만 제공한다.
- `attempts.csv`: 후보별 센서/영상 판정 및 시각. 헤더만 제공한다.
- 기록값의 `true/false`는 확인한 경우에만 사용하며 미확인은 `unknown`, 해당 없음은 `not_applicable`로 구분한다.
- 각 실행의 설정 사본, Git 상태, 영상, 로그와 시작/종료 사진은 `run_id`별 디렉터리에 보관한다. 원자료와 실패 시행을 삭제하지 않는다.

기존 기록의 집계는 `python3 docs/report/최종보고서/analysis/summarize_evidence.py`로 재현한다. 이 스크립트는 보관한 9월 8일 로그 전용이며 새 시험의 센서 판정이나 물리적 결과를 자동 확정하지 않는다.
