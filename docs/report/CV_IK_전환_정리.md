# 전통 CV + IK 전환: 설계 근거와 정량 결과

최종보고서·포스터 작성용 정리 문서. 모든 수치는 2026-08-31 실장비 측정값이며,
측정 방법과 재현 명령어를 함께 적었다.

---

## 1. 전환 배경

착수 단계의 설계는 모방학습(ACT) 기반이었다. 중간보고서에서 세 후보
(Task ID 기반 ACT / SmolVLA / 하이브리드 ACT–CV·IK)를 제시하고 동일 조건
비교로 선정하기로 하였으며, 반복 rollout 결과 ACT 단독 경로의 파지 성능이
미션 요구 수준에 도달하지 못하는 것으로 판단하여 **채점·시연 경로를 전통 CV와
역기구학(IK) 단독 구성으로 전환**하였다.

### 규정 적합성

과제 공지상 "모델"은 신경망을 의미하며 **신경망은 하나만 사용**한다는 조항은
상한이지 필수 요건이 아니다. 임계값 기반 색상 분할, 기하 계산, 역기구학은
비학습 알고리즘으로 모델에 포함되지 않는다. 따라서 CV+IK 단독 구성은 규정에
부합한다. 기존 ACT 학습 자산과 코드 경로는 삭제하지 않고 보존하였다.

### 전환의 공학적 근거

| 항목 | 판단 |
|---|---|
| 문제 구조 | 고정 탑다운 카메라, 평면 위 강체 단색 블록, 고정 지정영역 — 기하학적으로 완전히 규정됨 |
| 실패 진단성 | CV+IK는 실패 원인이 캘리브레이션·색 임계값·IK 중 하나로 국소화되고 수치로 측정됨 |
| 반복 주기 | 재학습 불필요. 파라미터 조정 주기가 분 단위 |

## 2. 시스템 구성

```
탑다운 카메라 ──HSV+형상 검출──▶ 블록 픽셀 좌표
                                      │
                            homography (H) │ 픽셀 → 로봇 베이스 좌표
                                      ▼
                              역기구학 (IK) ──▶ 관절 각도
                                      │
                              관절공간 보간 + 안전 클램프
                                      ▼
                                   SO-101
```

상태 기계(FSM): `SELECT → PICK → VERIFY → TRANSPORT → PLACE → SELECT`

- 1차 미션(운반)과 2차 미션(적재)은 **PLACE 전략만 교체**하고 나머지 경로를 공유
- VERIFY는 파지가 확인되지 않으면 절대 TRANSPORT로 진행하지 않음
- 파지 실패 시 재시도, 지정 횟수 초과 시 해당 블록 스킵 (한 블록이 시간 예산을
  독점하지 못하게 함)

## 3. 정량 측정 결과

### 3.1 카메라 및 광학계

| 항목 | 값 | 비고 |
|---|---|---|
| 해상도 | 1280×720 | 640×480 대비 코너 정밀도 1.49배 |
| 체스판 코너 검출 | 349~408개 | 팔에 일부 가려진 상태 |
| 마운트 드리프트 | p95 **0.32 px** | 기준 2px, 10분 측정 |
| 체스판 homography 잔차 | RMS **0.39~0.48 mm** | 렌즈 왜곡 무시 가능 수준 |

체스판 코너만으로 적합한 homography의 잔차가 0.4mm이고 화면 중심으로부터의
거리와 상관관계가 없다(상관계수 0.065). **즉 카메라·광학·평면 변환 수식에는
문제가 없다.** 이는 이후 오차 원인을 로봇 측으로 특정하는 근거가 된다.

### 3.2 픽셀 → 로봇 좌표 캘리브레이션

작업영역에 고르게 분포한 **15개 지점**에서, 그리퍼로 블록을 파지한 상태의
순기구학(FK) 좌표와 해당 블록의 영상 중심 좌표를 짝지어 homography를 추정하였다.

| 항목 | 값 |
|---|---|
| 적합 잔차 (RMS) | 11.98 mm |
| Leave-One-Out 평균 | 13.99 mm |
| Leave-One-Out 최악 | 28.56 mm |

목표치(RMS 5mm)에 도달하지 못하였다. 원인 규명을 위해 아래 §4의 가설 검증을
수행하였다.

### 3.3 역기구학

placo 기반 IK는 초기값(seed)에 매우 민감하여, 현재 자세를 초기값으로 사용하면
측방 이동 시 200~350mm 오차로 수렴한다. 이를 **탑다운 자세 시드 테이블**
(순기구학 그리드 사전 계산, 디스크 캐시)로 해결하였다.

| 항목 | 값 |
|---|---|
| 모델 내 수렴 오차 | 25개 지점 중 23개에서 **0.00 mm** |
| 탑다운 도달 반경 | 0.03 ~ 0.32 m |
| 시드 테이블 생성 | 13초 (1회, 이후 캐시 재사용) |

도달 반경을 벗어난 2개 지점은 오차를 크게 보고하여 **도달 불가를 정상적으로
검출**하였다.

### 3.4 그리퍼 회전 각도 설계 (서보 과열 사고 및 해결)

초기 구현은 그리퍼 회전(yaw)을 로봇 베이스 기준 **고정 절대 방향**으로 두었다.
이 경우 `shoulder_pan`이 회전한 만큼 `wrist_roll`이 반대로 비틀어 절대 방향을
유지해야 하며, 작업영역을 가로지르며 **약 80도가 휘둘리고 한계각(-125도)에
도달**한다. 실제 시험 중 해당 서보가 **과열 보호 정지**되었다.

해결: 그 위치에서 `wrist_roll`이 중립(0)이 되는 yaw를 자동 선택하도록 변경.

| | 고정 절대 방향 | 중립 기준 (현재) |
|---|---|---|
| `wrist_roll` 최대 편차 | 125도 | **3.7도** |

정사각형 블록은 90도 대칭이므로, 블록 각도에 정렬해야 하는 경우에도
**중립에서 ±45도 이내**(실측 최대 43.5도)로 해결된다.

### 3.5 파지 검증

`Present_Position`과 `Present_Load`를 함께 사용하여 파지 성공을 판정한다.
빈손으로 닫으면 그리퍼가 끝까지 닫히지만, 블록을 물면 중간에 멈춘다.

| 조건 | 그리퍼 위치 | 부하 |
|---|---|---|
| 블록 파지 (3회) | 44.1 ~ 44.3 | 500 (포화) |
| 빈손 (3회) | 3.4 | 39 ~ 41 |

두 분포가 완전히 분리되어 판정 임계값을 각 분포의 중앙값으로 설정하였다
(위치 20.0 / 부하 200.0). 오분류는 관측되지 않았다.

### 3.6 그리퍼 개구부와 오차 허용량

| 항목 | 값 |
|---|---|
| 명령 가능 범위 | 0 ~ 100 (정규화) |
| 개방 시 턱 간격 | 약 70 mm |
| 블록 크기 | 40 mm |
| **위치 오차 허용량** | **± 15 mm** |

캘리브레이션 LOO 오차 15개 중 10개(67%)가 이 허용량 안에 든다.

## 4. 검증 과정에서 배제한 가설

캘리브레이션 오차의 원인을 특정하기 위해 네 가지 가설을 수립하고 각각
정량 검증하여 배제하였다. **이 과정 자체가 오차의 성격을 규명하는 근거가 된다.**

| # | 가설 | 검증 방법 | 결과 |
|---|---|---|---|
| 1 | 파지 높이(z) 불일치로 인한 시차 오차 | z 편차를 std 8.0mm → 1.4mm로 통제 후 재측정 | RMS 개선 없음 |
| 2 | 손목 각도 불일치 | `wrist_roll` 편차를 148도 → 0.4도로 통제 후 재측정 | RMS 개선 없음 |
| 3 | 공구 좌표계의 고정 오프셋 | 3차원 오프셋 벡터를 격자 탐색으로 최적화 | 11.98 → 10.57 mm (미미) |
| 4 | 위치에 따라 매끄럽게 변하는 계통 오차 | 잔차 역거리가중 보간 후 LOO 재평가 | 13.99 → 14.45 mm (악화) |

**가설 4의 기각이 결정적이다.** 오차가 위치에 따라 매끄럽게 변하는 계통
오차였다면 보간이 이를 포착했어야 한다. 포착되지 않았다는 것은 오차가
**점 단위로 무작위**임을 의미하며, 이는 로봇의 기구학 모델 오차가 아니라
**데이터 수집 과정의 측정 편차**를 가리킨다.

가장 유력한 원인은 **평행 그리퍼의 구속 부족**이다. 평행한 두 턱은 블록을
닫히는 축 방향으로만 구속하며, 그에 수직한 방향(턱 길이 방향)으로는 전혀
구속하지 않는다. 따라서 캘리브레이션 시 작업자가 블록을 턱 사이에 놓는
위치가 육안 판단에 의존하게 되고, 여기서 발생하는 편차가 그대로 기록된다.

### 부수적으로 확인된 기구 특성

`gripper_frame_link`(순기구학 기준점)가 `wrist_roll` 회전축에서 **약 8mm
벗어나** 있다. 팔 자세를 고정한 채 손목만 회전시키면 기준점이 **최대 13.7mm
이동**한다. 이 때문에 캘리브레이션 시 손목 각도가 점마다 다르면 서로 다른
오프셋이 기록에 혼입된다.

## 5. 현재 한계와 대응 설계

### 한계

절대 위치 정확도는 **RMS 약 12mm, 최악 약 29mm** 수준이다. 재캘리브레이션을
2회 수행하고 4개 가설을 배제한 결과, 이 규모의 오차는 현재 절차로는 추가
개선이 어렵다고 판단하였다.

### 대응 설계

정확도를 더 높이는 대신, **해당 오차 규모를 전제로 견고하게 동작하도록** 설계한다.

1. **넓은 개구부** — 턱 간격 70mm로 ±15mm 오차까지 흡수
2. **파지 검증 후 진행** — 파지 실패 시 운반하지 않고 즉시 중단, 재시도
3. **도달 가능성 사전 검사** — IK 오차가 임계값을 넘으면 실행 전 중단
4. **위치별 최대 높이 자동 탐색** — 탑다운 자세 유지 가능한 최대 높이로 들어올려
   운반 중 간섭 최소화
5. **(계획) 손목 카메라 기반 근접 보정** — 파지 직전 근거리에서 블록의 상대
   위치를 재측정하여 잔여 오차 보정. 절대 좌표를 사용하지 않으므로 캘리브레이션
   오차와 무관하게 동작

## 6. 안전 설계

제어 경로에 안전장치를 다중으로 중첩하였다.

| 계층 | 내용 |
|---|---|
| 궤적 보간 | 틱당 관절 변화량 상한 |
| 로봇 펌웨어 | `max_relative_target` 상대 이동 클램프 (항상 활성) |
| IK 게이트 | 도달 불가 목표는 실행 전 차단 |
| 파지 게이트 | 파지 미확인 시 운반 단계 진입 금지 |
| 종료 처리 | 성공·실패 무관하게 그리퍼 개방 후 홈 복귀 |

궤적은 항상 **명령된 자세가 아니라 측정된 현재 자세**에서 시작하여, 이전
동작이 목표에 못 미친 경우에도 급격한 도약이 발생하지 않는다.

## 7. 남은 작업

- [ ] 실기 파지 성공률 측정 (10회 이상, 위치 분산)
- [ ] 손목 카메라 기반 근접 보정 구현 및 효과 비교
- [ ] 색상별 HSV 임계값 실환경 튜닝 (현재 값은 합성 데이터 기준)
- [ ] 지정영역 테이프 부착 후 영역 좌표 등록 및 슬롯 배치 구현
- [ ] 2차 미션(적재) PLACE 전략 구현 및 5초 유지 검증

## 8. 포스터용 핵심 수치

```
카메라 마운트 드리프트      p95 0.32 px      (기준 2 px)
체스판 homography 잔차      RMS 0.4 mm       광학계 정상 확인
픽셀→로봇 캘리브레이션      RMS 12 mm        15점, LOO 최악 29 mm
IK 모델 내 수렴 오차        0.00 mm          25점 중 23점
탑다운 도달 반경            0.03 ~ 0.32 m
손목 회전 편차              125도 → 3.7도    서보 과열 해결
파지 판정 분리도            44.2 vs 3.4      완전 분리, 오분류 0
그리퍼 개구부               70 mm            블록 40mm, 허용오차 ±15mm
```

**검증 과정에서 배제한 가설 4건** — 오차 원인을 측정으로 특정하고, 개선 불가
영역과 설계로 흡수할 영역을 구분함.
