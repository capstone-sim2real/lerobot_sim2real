## 평가 자료 안내

| 항목 | 정의 및 출처 |
|---|---|
| Task 1 | 180초 이내 블록 5개 구역 배치. 최종보고서 팀 집계 28/30회. |
| Task 2 | 팀이 제공한 4블록 적층 성공률 100%, 5블록 적층 성공률 67%. 30회 시행 기준이며 5초 유지 여부는 별도 제공되지 않았다. |
| 단일 블록 파지 | Task 구분 없이 100회 중 99회 성공. 재시도 포함 여부는 별도 제공되지 않았다. |

각 지표는 서로 다른 평가 항목이다. Task 2 성공률에서 5초 유지율을 추론하거나, 파지 성공률을 최초 시도 성공률로 해석하지 않는다. 기존 보고서의 원자료는 당시 평가 기록으로 보존한다.
