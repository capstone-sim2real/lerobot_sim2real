## 작성 전제 및 사용 시 주의

사용자 요청에 따라 Task2는 계획대로 완성한 상황을 가정하여 서술했다. 이 포스터는 현재 코드의 구현 완료나 실험 검증을 증명하는 자료가 아니다. 공통 인식·파지·운반 흐름과 PLACE 단계만 바꾸는 구현 목표를 반영했다. 180초·300초·5초는 과제 제한 및 판정 조건이며, 측정된 수행 시간이나 성공률이 아니다.

로봇팔, 검출 오버레이, 적층 장면은 설명용 생성 이미지이며 실제 장비 사진이나 실험 결과 화면이 아니다. 인쇄 전 실제 사진 및 검출 화면으로 교체하고, 학교 로고는 원본 양식의 로고를 사용하는 것을 권장한다. 양식의 색상·머리말·팀 정보·세 구획·꼬리말 구성은 유지하되 생성 이미지이므로 원본과 픽셀 단위로 동일하지는 않다.

현재 PNG는 화면 검토용 해상도이며, 대형 포스터 인쇄에는 원본 편집 양식에 내용과 도식을 옮겨 고해상도로 내보내는 것이 적합하다. 원본 첨부 이미지의 2806 × 3973 해상도를 복원한 파일은 아니다.
