# 발표 디자인 방향 비교

2026-09-11. 사용자가 요청한 세 방향을 비교하기 위한 **새로 만든 디자인 시안**이다. 외부 발표의 캡처나 확정한 최종 PPT가 아니다. 각 방향은 표지와 파지 확인 설명 장으로 구성한다.

- A: 큰 사진과 여백을 사용하는 흰색 키노트 스타일
- B: 굵은 타이포그래피와 강한 대비를 사용하는 어두운 테크 스타일
- C: 따뜻한 종이색, 명조 제목과 얇은 구분선을 사용하는 편집 디자인 스타일

사진은 기존 보고서의 `figures/grasp_lifted.jpg`를 SVG 화면 안에서 확대/배치하였다. 로봇 자세나 블록 위치를 생성하거나 변경하지 않았다. 본문은 파지 확인 후 운반, 미확인 시 다른 후보를 검토하는 설계 원칙의 설명이다. 새로운 실험 결과나 성능 수치를 추가하지 않았다.

## 파일

- `A_preview.jpg`, `B_preview.jpg`, `C_preview.jpg`: 표지와 본문을 나란히 비교
- `A_cover.png` ~ `C_body.png`: 1600×900 개별 화면
- 같은 이름의 SVG: 편집 가능한 벡터 원본, 사진 포함
- `design_directions.pdf`: A 표지/본문 → B 표지/본문 → C 표지/본문 순서의 6쪽 PDF
- `build_previews.py`: 로컬 Cairo/librsvg로 재생성하는 스크립트

## 외부 참고 자료

- [Apple WWDC25 Keynote](https://developer.apple.com/videos/play/wwdc2025/101/): 큰 시각 자료와 짧은 메시지 중심의 발표 방향 참고
- [토스 SLASH24, Yarn Plugin으로 우아하게 자동 로깅하기](https://static.toss.im/slash24/QR/slash24-09.pdf): 판단과 처리 과정을 단계별로 설명하는 실제 기술 발표 참고. 원본 슬라이드는 이 폴더에 복제하지 않음

C의 종이색/명조/구분선 조합은 이번 비교를 위해 별도로 제안한 디자인이다. 세 시안 모두 외부 발표의 특정 화면을 복제한 템플릿이 아니다.

스타일을 선택한 뒤 기존 12장 발표 구성에 적용한다. 현재 Genspark 원고와 기존 팀원 PPT는 변경하지 않았다.
