## 4. 각 장에서 강조할 설명

### 4번: 전환의 이유

- ACT 58%와 CV+IK 시험 결과를 비교 막대그래프로 만들지 않는다. 과제 단위와 조건이 다르다.
- 제한된 블록/평면 조건을 활용하고, 검출 좌표/계획 가능 여부/접촉 상태를 각각 확인할 수 있도록 설계했다는 판단을 설명한다.
- 센서 판정은 학습 정책과도 결합할 수 있다. 학습 방식에는 파지 감각을 추가할 수 없다는 식으로 설명하지 않는다.
- 112개 에피소드, SmolVLA 51개/8,000스텝, gRPC 구조는 구두 질문이 있을 때 설명한다.

### 7번: 캘리브레이션 절차와 오차

- 같은 블록 위치에서 팔이 접촉한 장면과 팔을 치운 장면을 보여준다.
- 관절값→FK 기준점, 영상→블록 중심, 대응점→평면 변환의 관계를 설명한다.
- 카메라 픽셀에서 로봇 베이스 좌표(mm)로 변환한다. 체스판 원점을 로봇 원점으로 오해하게 그리지 않는다.
- RMS는 대응점 적합 잔차, LOO는 점을 하나 제외했을 때 해당 점의 예측 오차이다. 두 숫자를 실제 턱의 독립 측정 정밀도로 표시하지 않는다.
- 네 단계 RMS 변화는 별도 수집 조건의 개발 이력이다. 대응점 수 증가만의 효과로 해석하지 않는다.

### 9번: 발표의 핵심 구현

- 중심 후보가 실행 불가능해도 실행 가능한 다른 후보를 검토한다.
- 파지 후보를 실행한 뒤 그리퍼 위치와 부하로 상태를 확인한다.
- 파지가 확인되지 않으면 운반으로 진행하지 않는다. 다음 후보, 순회 보류, 재선택으로 연결한다.
- 후보 소진을 영구 포기로 그리지 않는다. 최신 코드의 분기와 보고서 PICK 도식을 따른다.
- 후보 이동은 반경/접선 방향의 설정값이다. 화면 좌우와 로봇 좌표축을 섞거나 임의의 대각 후보를 추가하지 않는다.
- 원본의 파지/빈손 사례는 서로 다른 위치/방향이다. 동일 조건의 보정 전후 비교처럼 배치하지 않는다.

### 10~11번: 성과와 한계를 같은 기록으로 설명

- 9월 2일 영상은 동작 사례, 9월 8일 로그는 외부 제한 시험이다. 날짜를 명시하고 서로의 결과로 대체하지 않는다.
- 14회는 파지 후보 실행 시작 횟수, HELD/EMPTY는 센서 판정이다. 물리적 파지 성공률로 나누지 않는다.
- 마지막 블록은 후보를 실행한 뒤 두 번 EMPTY, 세 번째 후보 접근 중 중단되었다. 검출 자체가 실패했다고 설명하지 않는다.
- 한 블록 첫 PICK 51.5초, 최초 선택부터 재선택 후 해제까지 69.8초이다. 본문에는 51.5초, 상세 질의에는 69.8초를 사용한다.
- 36초는 180초/5개로 계산한 평균 시간 예산이며 현재 실행의 강제 블록별 중단값이 아니다.
- 외부 180초 제한에는 초기화가 포함된다. 로그의 마지막 시간을 늘려 정확한 180초 물리 정지로 도식화하지 않는다.

- 실측 데이터 차트는 보고서의 원자료로 작성하고 축, 단위, 시행 범위를 표시한다.
- 기술 이름은 OpenCV, PlaCo, LeRobot처럼 출처를 드러내고 팀이 추가한 처리와 구분한다.
- 문장 구분에는 쉼표나 슬래시를 사용한다. 역할 설명은 명사형으로 마친다.
- 마지막 장에 기여와 남은 검증을 함께 남겨두고 질의응답을 진행한다.

## 7. Genspark에 전달하는 순서

1. `GENSPARK_BRIEF_10MIN.md`의 확정 내용과 14장 순서를 전달한다.
2. 위 소재 표에서 고른 실제 이미지와 검증된 도표를 함께 제공한다. 전체 과거 PPT를 동등한 사실 근거로 섞어 넣지 않는다.
3. 시안에서 먼저 2/7/9/10번의 미션 수치, 좌표 단위, 분기, 결과 표현을 확인한다.
4. 10분 리허설에서 길어지면 4번 학습 설명과 8번 IK 설명을 줄인다. 9~11번의 판단 조건과 결과 해석을 우선 보존한다.
5. 추가 짧은 시험이 확보되면 10번에 시행별 실제 인정 블록 수/종료 사유를 갱신한다. 결과가 없으면 현재 기록을 유지한다.

Genspark용 확정 원고는 별도 파일에 두어, 위 검토표의 잘못된 표현이 생성 입력에 다시 섞이지 않도록 한다.
