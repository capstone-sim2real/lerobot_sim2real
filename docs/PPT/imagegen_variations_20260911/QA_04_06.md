# 04–06 디자인 시안 검토

세 이미지 모두 내장 image_gen으로 새로 생성한 뒤 원본을 보존하고 이 폴더로 복사함. generatedImage로 표시하고 저장본을 view_image로 재확인함.

## 공통 확인

- 각각 PNG 2048×768, 전체 8:3 비율.
- 가로 3개, 세로 2개의 같은 크기 슬라이드, 총 6개 패널 확인.
- 제목, 시스템 구성, 비전, 캘리브레이션, 파지 확인, 결과의 6장 배치 확인.
- RMS 8.18 mm, 최대 LOO 26.64 mm, 슬롯 해제 4회, 후보 14회, HELD 4 / EMPTY 9 / 중단 1 유지.
- 전체 미션 미완료와 적재 실기 미수행 표기 확인.
- 센서 미확인 분기는 운반으로 향하지 않고 다음 후보로 연결됨.
- 로봇 그림과 검출 장면은 생성한 개념 이미지이며 실제 실험 사진으로 사용하면 안 됨.
- 최종 PPT 제작 시 확정 원고와 실제 실험 사진/도식으로 본문과 삽화를 교체할 디자인 참고 이미지임.

## 04_midnight_cyan.png

- 어두운 남색과 밝은 시안의 대비, 큰 수치와 여백으로 구성.
- 핵심 한국어와 수치는 모두 읽을 수 있음.
- 그림 안 작은 영문 슬로건이 추가 생성됨. 최종 발표에는 삭제 권장.
- 좌표 개념도에 X,Y,Z가 표시됨. 실제 호모그래피 설명 시 평면의 x,y로 정리 권장.

## 05_blueprint.png

- 밝은 도면 그리드와 남색, 주황으로 구성. 세 시안 중 학술 발표용 대비와 다이어그램 가독성이 가장 무난함.
- 작은 축 표기가 중복되고 좌표면 배치가 모호하므로 최종 PPT에서 확정 도식으로 교체 필요.
- 비전 도식의 경계 설명은 작업 영역과 지정 배치 영역을 구분하여 다시 작성할 것.
- 주요 수치와 실패 분기는 정상.

## 06_industrial_mono.png

- 백색/차콜 분할, 안전노랑, 큰 숫자와 기하학적 편집 구성.
- 초기본에서 다음 후보 아래에 '다른 블록 시도'라는 부정확한 보충 문구가 생성되었음. 내장 image_gen 편집으로 이 부연만 삭제한 06_industrial_mono_v2.png를 최종본으로 생성함. 해당 박스에는 '다음 후보' 한 줄만 남았으며 3×2 배치, 주요 수치, 분기 방향과 다른 본문이 시각적으로 유지됨. 초기본은 drafts/06_industrial_mono_initial.png에 보존함.
- 비전 도식의 '영역 제외'는 작업 영역 외부와 지정 배치 영역 내부를 따로 표현해야 함. 현재 합성 장면을 판정 규칙 설명에 그대로 쓰지 않을 것.
- 주요 수치와 센서 확인/미확인 분기는 정상.
