# Genspark 전달용 발표 제작 지침

한국어 학부 졸업과제 발표 슬라이드를 총 14장 제작한다. 1~12장은 약 10분 발표용, 13~14장은 질의응답용 부록이다. 영상 재생 시간과 질의응답은 설명 시간에 포함하지 않는다. 아래 순서와 사실을 유지하고, 새로운 성능 수치나 수행 실적을 생성하지 않는다.

공식 과제명: 컴퓨터 비전과 역기구학 기반 SO-ARM101 로봇팔의 블록 이동 및 적재 시스템

팀: Team Sim2Real, 부산대학교, 윤민석/김주환/이동근

중심 메시지: 실제 장비의 인식, 좌표, 접촉 문제에 대응하여 파지 확인과 재시도를 갖춘 CV+IK 제어 시스템을 구현하고, 실행 기록으로 복구 동작과 시간 비용을 분석하였다.

## 디자인 기준: Steel / Sky

첨부한 01_design_reference.png는 6개 슬라이드의 스타일을 한 화면에 모은 참고 이미지다. 최종 산출물은 가로 3칸/세로 2칸의 이미지가 아니라, 각각 16:9인 독립 슬라이드 14장이다. 참고 이미지를 통째로 붙이거나 잘라서 최종 슬라이드로 사용하지 않는다.

- 정확한 색상: #355872(제목/본문/선/어두운 배경), #7AAACE(보조 도형), #9CD5FF(표지/강조 면), #F7F8F0(기본 배경/어두운 면의 글자).
- PNG를 스포이트로 추출하지 말고 위 HEX를 직접 지정한다. 기본 본문은 #F7F8F0 배경에 #355872로 표시한다. 옅은 파랑은 긴 본문 글자색으로 쓰지 않는다.
- 표지는 하늘색 배경, 큰 CV+IK 타이포그래피, 작은 추상 블록 형태로 구성한다. 본문은 넓은 여백, 굵은 제목, 얇은 선, 간결한 다이어그램을 사용한다.
- 7번 캘리브레이션 장은 #355872의 어두운 배경과 #F7F8F0 글자로 전환한다. 나머지 본문은 밝은 배경을 기본으로 한다.
- 표지 외 슬라이드의 구석에는 작은 사각형 장식만 제한적으로 사용한다. 반복되는 둥근 카드, 과도한 그림자/그라데이션, 네온, 불필요한 영어 장식 문구는 넣지 않는다.
- 미완료 항목도 같은 팔레트 안에서 굵기, 테두리, 반전 면과 명확한 문구로 구분한다. 주황색 등 새 강조색을 추가하지 않는다.
- 실제 실험 사진은 자연색을 유지한다. 팔레트는 문서의 배경/글자/도형에 적용하며, 증거 사진의 블록 색이나 위치를 바꾸지 않는다.
- 16:9, 제목 32~38pt, 본문 22~26pt를 목표로 한다. 한글은 Noto Sans KR 등 지원되는 고딕 한 종류로 통일한다. 긴 공식 과제명은 표지의 작은 부제에 둔다.
- 장마다 핵심 주장 하나, 주요 설명 최대 3개. 자세한 조건/한계는 발표자 노트와 부록으로 배치하되 결과 해석에 필수인 미완료/미측정 표시는 본문에도 유지한다.
- 텍스트, 표, 흐름도는 가능한 한 편집 가능한 개별 요소로 만든다. 슬라이드 전체를 한 장의 생성 이미지로 굳히지 않는다.
- 실제 사진/로그는 첨부 자료를 사용한다. 로봇 자세, 블록 배치, 검출 화면, 실험 결과를 새로 생성하지 않는다. 빠진 장면은 필요한 사진의 자리표시자로 남긴다.
- 개념도는 개념도라고 표시한다. 그래프는 제공된 수치만 사용하고 시행 범위/날짜/단위를 표시한다.
- 명칭 구분에는 쉼표나 슬래시를 사용한다. 목차, 제출 일정, 별도의 감사 슬라이드는 추가하지 않는다.
- 본문 발표자 노트의 목표 시간은 합계 9분 20초다. 화면 전환 여유 40초를 포함해 약 10분으로 구성한다. 영상과 질의응답은 별도다.

## 자료의 역할과 우선순위

- 구성/문구/평가 범위: 이 제작 지침(02_slide_brief.docx).
- 색과 타이포그래피/여백: 01_design_reference.png. 이미지 안의 축약 문구는 최종 내용의 원문이 아니다.
- 기술 설명과 수치의 근거: 03_source_report.pdf 및 함께 제공한 원본 사진/집계 파일.
- 외부 웹 검색으로 우리 팀의 성능이나 실험 이력을 보충하지 않는다. 파일 간 충돌이 발견되면 임의로 수치를 합치지 말고 해당 부분을 질문 또는 검토 항목으로 남긴다.
- ACT 29/50회는 초기 단일 블록 결과다. 최종 CV+IK 성능 비교로 쓰지 않는다.
- 슬롯 해제 4회는 인정 블록 4개 또는 미션 성공률 80%가 아니다. 적재는 실기 검증 미수행이다.

## 1. 표지 — 15초

화면: 큰 제목 “CV+IK 기반 블록 조작 시스템”, 공식 과제명 부제, Team Sim2Real, 부산대학교, 윤민석/김주환/이동근. 하늘색 배경 위 큰 CV+IK 글자와 작은 추상 블록 도형. 실제 장비 사진은 2~3장에 배치한다.

설명 요지: 고정 카메라와 CV+IK, FSM을 연결한 블록 조작 시스템의 구현과 실행 결과를 소개한다.

## 2. 다섯 블록을 제한시간 안에 이동하는 과제 — 35초

화면:

- 블록 5개, 개당 40×40×20mm
- 1차: 180초 이내 20×10cm 지정 영역 배치
- 2차: 300초 이내 블록 적재 후 5초 유지

하단 범위: 이동 제어의 실기 실행, 적재 제어 구조 구현과 검증 준비.

시각 자료: 작업 영역 사진과 미션별 작은 도식. 적재 도식에는 과제 목표라고 표시한다.

노트: 1차 미션은 경계 2cm 걸침, 세워짐, 일부 겹침을 허용하지만 적재는 인정하지 않는다. 적재 실기는 아직 수행하지 않았다.

## 3. 검출부터 배치까지 실제 장비에서 연결 — 35초

화면: 실제 시연 2~3컷, `검출 → 파지 → 운반 → 배치`.

사진 표기: 2026-09-02, 순차 동작 사례.

노트: 실제 로봇에서 각 단계를 연결해 반복 동작을 관찰했다. 이 영상의 재생 시간을 공식 미션 완료시간으로 사용하지 않는다. 선택적으로 한 사이클의 영상 20~30초를 별도 재생한다. 편집이나 배속을 적용한 경우 표시한다.

## 4. 실패 단계를 확인할 수 있도록 CV+IK 선택 — 45초

화면:

- 초기 ACT/SmolVLA 시도, ACT 단일 블록 이동 29/50회 성공
- 관측 입력, 동작 계획, 실제 접촉을 분리해서 확인할 필요
- 고정 평면과 정해진 블록 조건을 활용한 CV+IK/FSM 통합

시각 자료: 초기 접근, 관찰된 어려움, 최종 선택의 세 단계.

노트: ACT 58%는 초기 단일 블록 결과이며 최종 방식과 동일 조건 비교를 수행하지 않았다. SmolVLA는 목표 근처 접근을 관찰했으나 안정적인 파지에는 도달하지 못했다. 학습 방식 자체에 센서 확인을 추가할 수 없다는 주장을 하지 않는다.

## 5. 인식과 동작을 FSM으로 연결 — 55초

화면 상단: `카메라 → CV → 베이스 좌표/IK → FSM → 로봇`.

관제 화면은 카메라와 측정 상태를 받아 보여주는 별도 가지로 배치한다. 관제 오버레이를 로봇 제어 입력으로 연결하지 않는다.

화면 하단: `SELECT → PICK → VERIFY → TRANSPORT → PLACE → SELECT`.

분기: 파지 미확인 시 재시도/재선택. 파지 확인 후 운반.

노트: 상태 판단, 후보 처리와 실제 장비 입출력을 연결했다. Task2는 PLACE 전략을 교체하는 구조이며 실제 적재 검증은 별도로 남아 있다.

## 6. 색과 형상, 영역 조건으로 대상 선택 — 45초

화면:

- HSV로 색 후보 생성
- 면적/종횡비/채움 정도로 형상 검사
- 지정 영역 내부와 작업 범위 밖 후보 제외

시각 자료: 실제 검출 화면에 블록 후보와 지정 영역을 표시한다. 원본에 없는 검출 성능이나 적용 전후 차이를 만들지 않는다.

노트: 빨간 테이프와 블록은 색이 유사하므로 형상을 함께 사용했다. 웹 뷰어에서 검출 결과, 파지 후보와 FK 투영 위치를 관찰한다. 필터 정확도나 속도 개선율은 별도로 측정하지 않았다.

## 7. 픽셀과 로봇 좌표를 대응시키고 잔여 오차 측정 — 60초

화면: 같은 대응점 P4의 calibration_p4_contact.jpg와 calibration_p4_clear.jpg를 같은 확대 범위로 나란히 배치한다. 어두운 스틸 배경을 사용한다.

- 왼쪽: 블록 윗면에 기준점을 맞추고 관절값/FK 기록
- 오른쪽: 팔을 치운 뒤 블록의 영상 중심 확인
- 아래: 픽셀 좌표 → 로봇 베이스 좌표(mm)

수치: 2026-09-08 재수집 9점, 적합 RMS 8.18mm, 최대 LOO 26.64mm. 개발 목표 RMS 5mm 미만, 최대 LOO 8mm 미만에 미달.

노트: 기록되는 FK는 관절값으로 계산한 모델 기준점이다. 두 지표는 실제 턱의 위치 정밀도를 독립 측정한 값이 아니다. 좌표/접촉의 잔여 오차 때문에 파지 확인과 재시도를 함께 적용했다.

## 8. 실행 가능한 자세와 중립 손목 방향 선택 — 45초

화면:

- 후보별 IK 도달성 검사
- 작업 위치의 중립 손목 방향 선택
- 블록의 90° 대칭을 활용한 면 정렬

시각 자료: 중립 자세와 블록 정렬 방향을 나타낸 간단한 개념도.

노트: 초기에는 고정 방향을 유지하면서 손목이 비틀리고 과열 보호 정지가 발생했다. 이를 계기로 중립에 가까운 방향을 선택하도록 변경했다. 이 개념도를 실측 온도 개선이나 실제 턱 정밀도 그래프로 표현하지 않는다.

## 9. 파지 확인과 대체 후보로 실패에 대응 — 70초

화면 왼쪽: 판단 흐름도.

1. 중심 후보 실행 가능 여부 확인
2. 불가능하면 다른 실행 가능한 후보 검토
3. 접근/닫기 후 그리퍼 위치와 부하 확인
4. 확인되면 운반, 미확인이면 다음 후보/순회 보류/재선택

화면 오른쪽: 실제 파지 사진과 빈손 사례 사진.

작은 수치 표기: 파지 관측 사례 위치 20.99/절대 부하 500, 빈손 관측 사례 위치 2.49/절대 부하 44. 위치는 서보 정규화값이며 mm가 아니다.

핵심 문장: 파지가 확인되지 않으면 운반으로 진행하지 않음.

노트: 파지 후보는 도달성 검사를 통과해야 실행한다. 서로 다른 위치/방향에서 얻은 사진과 센서값이므로 동일 조건의 전후 비교나 판정 정확도로 제시하지 않는다. FK 목표 거리 약 1~2mm인 실패 사례도 있어 모델상의 도달과 실제 접촉을 구분한다.

## 10. 전체 시험에서는 네 번 해제 후 미완료 — 60초

화면 제목 아래 조건: 2026-09-08, 외부 180초 제한 시험 1회, 30Hz.

주요 결과:

- 후보 실행 시작 14회
- 센서 판정 HELD 4회, EMPTY 9회, 판정 전 중단 1회
- 슬롯 해제 동작 4회, 마지막 블록 잔류로 미완료

시각 자료: 후보 14회의 판정 분포를 횟수로 표시한 띠 또는 간단한 표. 비율이나 성공률 원형 차트를 사용하지 않는다.

하단: 인정 블록 수 미집계, 최종 방식의 반복 성공률 미측정.

노트: 센서 판정, 슬롯 해제 횟수, 사람이 규정에 따라 확인한 인정 블록 수는 서로 다른 항목이다. 9월 2일 시연 사진을 이 시험의 종료 사진처럼 표시하지 않는다.

## 11. 재시도는 파지 회복과 시간 비용을 함께 발생 — 50초

화면: 원본 실행 기록의 상태별 시간 흐름, 재선택 구간 강조.

핵심:

- 추가 후보와 재선택 이후 HELD를 얻은 사례
- 한 블록 첫 PICK 51.5초
- 평균 블록당 시간 예산 36초

노트: 해당 블록은 재선택 후 해제까지 최초 선택부터 69.8초가 걸렸다. 36초는 180초/5개로 계산한 평균 예산이며 강제 중단 설정값이 아니다. 재시도 적용/미적용 비교는 없어 평균 성공률 개선으로 일반화하지 않는다. 다음 개선은 후보별 시간 비용과 실패 사유를 함께 관리하는 것이다.

## 12. 통합 구현과 실패 분석, 남은 검증 — 45초

화면:

- 성과: 인식/좌표/IK/FSM, 파지 확인과 관제 도구의 통합
- 이동: 전체 미션의 동일 조건 반복 평가와 재시도 시간 관리
- 적재: 접근/하강 자세 등록, 통합 실행과 5초 유지 검증

작은 확장 문구: 관측과 행동, 검증된 결과 판정을 연결한 학습용 실행 기록으로 확장.
