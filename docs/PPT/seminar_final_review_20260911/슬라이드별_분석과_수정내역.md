# 졸업과제 세미나 발표자료 분석과 수정 내역

대상: `졸업과제_세미나_발표자료__최종_20260911.pptx`, 원본 14장.

슬라이드 XML에서 본문을 추출해 내용과 논리 흐름을 분석한 뒤, 원본 14장을 PDF와 PNG로 렌더링해 `view_image`로 각 장을 확인했다. 내장 영상 3개의 대표 프레임도 확인하고, 수정본을 다시 렌더링해 가독성과 겹침을 점검했다.

## 전체 진단

원본은 실제 장비와 관제 화면, 동작 영상이 충분해 시스템 구현을 보여 줄 재료가 있다. 그러나 설명 순서와 최신 결과 반영이 어긋나고, 글이 많은 장과 여백이 큰 장의 밀도 차이가 커서 완성된 발표의 인상이 약하다.

가장 큰 내용 문제는 원본 12장의 ‘적재 실기 미수행’과 13장의 ‘3층 적재 성공’이 충돌하는 점이다. 이번 작업 중 사용자가 3층 적재 성공을 확인해 주었으므로 최신 성과로 반영했다. 1차 미션 영상 마지막에는 5개 블록이 지정 영역에 모여 있는 장면이 확인되어 현재 결과의 중심에 배치했다. 사용자의 요청에 따라 발표 본문에서 날짜와 상세 기록 대조는 제거했다.

가장 큰 시각 문제는 원본 13장에서 영상이 본문을 덮는 현상이다. 원본 7·8·11·12장은 표와 설명이 많고, 3·5·9장은 여백에 비해 핵심 정보가 작다. 제목 위치, 페이지 번호, 영상 크기도 장마다 달랐다.

## 내용 정리 원칙

- 결과는 5개 블록의 운반 및 배치 장면, 사용자 확인을 받은 3층 적재 성공 중심으로 구성했다.
- ‘동일 조건 비교’, ‘최종 성공률 상승’, ‘파지 오분류 없음’, ‘과열 재발 없음’은 해당 주장에 맞는 검증 자료가 없어 본문에서 제거했다.
- IK 모델 내부 오차, 좌표 정합 오차, 실제 파지 여부를 구분했다.
- 필터 임계값, 과거 시행별 집계, 설정 차이와 상세 주의점은 발표자 노트로 옮겼다.
- 날짜 대신 문제, 설계, 동작, 성과, 남은 과제의 흐름을 사용했다.
- 내장 영상의 재생 길이를 실제 미션 완료시간이나 반복 성공률로 바꾸지 않았다.

**내용:** 팀명과 프로젝트 제목의 위계가 뒤바뀌어 프로젝트 이름보다 팀명이 먼저 눈에 들어온다. 긴 제목을 자연스럽게 읽을 수 있는 줄바꿈이 필요하다.

### 원본 4장 — 1차 미션 동작 영상 → 수정본 11장

**내용:** 영상에 없는 검출 내부 과정까지 외부 촬영 영상으로 확인할 수 있는 것처럼 설명되어 있다. 약 106초 영상을 전부 재생하면 10분 발표의 비중을 크게 차지한다. 원본의 특정 시험 날짜 표기는 기존 기록과 대조가 필요하다.

**수정:** 동작에서 볼 수 있는 검출 대상 선택과 접근, 운반과 배치, 반복의 관찰 포인트만 남겼다. 날짜는 본문에서 제거했다. 내장 영상을 유지하고 대표 화면을 최종 배치 장면으로 바꿨다. 발표자 노트에 약 25초 선택 재생을 제안했다.

### 원본 6장 — 카메라 인식 오버레이 영상 → 수정본 6장

**내용:** 앞 장과 색 후보, 형상 필터 설명이 중복된다. 웹 뷰어 자체의 기여인 검출 결과, 파지 후보, FK 표시의 의미가 더 명확해야 한다.

**수정:** 설명을 검출 결과, 파지 후보, FK 표시로 나누었다. FK는 관절값으로 계산한 모델 위치이며 실제 턱의 영상 추적과 다르다는 핵심만 남겼다. 영상은 유지하고 짧게 선택 재생하도록 노트에 안내했다.

### 원본 7장 — 기존 접근과 전환 배경 → 수정본 3장

**내용:** ‘세 후보를 동일 조건에서 비교’, ‘CV/IK에서 성공률 상승’은 현재 제공된 비교 실험 자료로 입증되지 않는다. 학습 데이터 수집량과 ACT 평가 횟수도 다른 항목이므로 혼동하지 않게 배치해야 한다. 성공률 29/50, 58%는 초기 ACT 결과로 유지할 수 있다.

**시각:** 표, 긴 전환 근거 세 문장, 장비 사진과 캡션이 한 장에 들어가 읽는 양이 많다. 표 내부 줄바꿈과 아래 문단의 시작 위치가 불규칙하다.

**수정:** 초기 ACT 결과, 확장 과정의 어려움, 최종 CV+IK 선택의 세 영역으로 구성했다. 전환 근거는 고정 작업 조건과 실패 추적 가능성으로 정리했다. 도입 직후로 옮겨 기술 선택을 먼저 이해하도록 했다.

### 원본 8장 — 전체 시스템 구조 → 수정본 4장

**내용:** 처리 파이프라인과 모듈별 역할 표가 같은 내용을 반복한다. 직선 FSM에는 실패 복귀가 드러나지 않는다. ‘시간 예산 관리’를 완성된 기능으로 포괄 표현하면 실제 1차 실행기의 외부 제한 시험과 혼동된다.

**시각:** 작은 글씨의 표가 면적을 크게 차지하고, 관제 화면은 너무 작아 읽을 수 없다. FSM 아래 주석이 도형과 가까워 답답하다.

**수정:** 상단은 영상, 평면 보정과 검출, 후보와 IK, 이동과 센싱의 흐름으로, 하단은 FSM으로 나누었다. VERIFY를 강조하고 미확인 시 복귀 경로를 추가했다. 라이브러리 이름을 표시해 외부 도구와 팀의 연결 작업도 설명할 수 있게 했다.

### 원본 9장 — 검출 게이트와 캘리브레이션 → 수정본 7장

**내용:** 제목은 검출과 캘리브레이션을 함께 말하지만 그림은 대응점 분포만 보여 준다. 15점에서 9점으로 향하는 화살표는 서로 다른 수집 조건을 단순 성능 개선으로 해석하게 할 수 있다. H를 구하는 절차와 오차 수치가 없다.

**시각:** 두 그림의 의미를 설명하는 캡션이 없고, 위아래의 여백이 크다. 화살표가 유일한 설명 요소여서 무엇이 바뀌었는지 알기 어렵다.

**수정:** 재수집 9점 분포를 한 장으로 크게 제시하고 RMS 8.18mm, 최대 LOO 26.64mm를 함께 표시했다. 오른쪽에는 TCP 정렬과 FK 기록, 팔을 치운 영상 좌표 기록, 대응쌍으로 H 추정의 절차를 넣었다. 수집 날짜는 본문에서 제외했다.

### 원본 10장 — IK와 파지 재시도 → 수정본 8장

**내용:** ‘전후좌우’와 ‘대각 4방향→좌우’가 서로 다르다. 후보 개수와 최대 재시도 횟수도 혼재되어 있다. 반경 0.32m를 모든 자세의 절대 도달 한계로 설명하거나, 턱 간격 70mm를 근거로 ±15mm 오차 흡수를 보장하는 것은 피해야 한다.

**시각:** 사진 형태의 개념 이미지에 설명 글자와 화살표가 포함되어 있어 확대와 편집에 불리하다. 실제 파지 장면과 개념적 후보 이동이 한 이미지에 섞인다.

**수정:** 중심과 전후좌우 후보를 편집 가능한 도형으로 다시 구성했다. 후보별 IK 검사, 실행 후 센서 확인, 중립 손목 정렬의 세 내용으로 정리했다. 모델 내부 도달 오차와 실제 파지 결과를 구분했다.

### 원본 11장 — 문제와 해결 → 수정본 9장

**내용:** 한계각 관련 125°와 모델 기반 중립 편차 3.7°를 같은 조건의 실측 전후 결과처럼 제시한다. ‘43.5° 실측’, ‘과열 재발 없음’도 독립 근거 확인이 필요하다. 파지 임계값 20/200은 기존 보고서의 12/200과 다르며 영상 당시 설정은 확인되지 않았다. `max_relative_target`을 로봇 펌웨어로 분류한 것도 정확하지 않다.

**시각:** 위쪽 세 문제 카드, 아래 큰 숫자, 안전 계층 표가 서로 경쟁한다. 정보가 많아 핵심 설계 판단보다 숫자와 구현 용어가 먼저 보인다.

**수정:** 색상 간섭, 손목 비틀림, 빈손 운반 위험의 세 문제와 대응만 남겼다. 하단에는 측정 자세, 관절 변화 제한, LeRobot 입출력 클램프, 파지 확인의 흐름을 배치했다. 성능 개선의 단정과 불확실한 임계값은 본문에서 제거했다.

### 원본 12장 — 결론과 요약 → 수정본 13장

**내용:** 기술 설정을 다시 나열해 앞 장들과 중복된다. ‘25개 중 23개 0.00mm’는 모델 내부 계산이며 ‘파지 오분류 없음’과 함께 제시하면 실제 성능으로 오해될 수 있다. 적재 미수행은 이번 사용자 확인 및 영상과 맞지 않는다. ‘분 단위 대응 가능’도 측정한 대응시간이 아니다.

**시각:** 7행의 긴 표가 화면 대부분을 차지한다. 작은 글씨와 여러 강조색 때문에 성과를 빠르게 파악하기 어렵고 페이지 번호 위치도 일관되지 않다.

**수정:** 확보한 성과와 남은 검증의 두 영역으로 나누고, 다음 일정은 하단 한 줄로 압축했다. 5개 블록 운반 및 배치, 파지 확인과 재시도, 관제 및 캘리브레이션 도구, 3층 적재 성공을 중심으로 구성했다.

### 원본 13장 — 향후 계획과 적재 영상 → 수정본 12장

**내용:** 이미 성공한 3층 적재를 ‘향후 계획’과 ‘잔여 과제’ 아래 배치해 성과가 약하게 보인다. 센서 판정으로 보상 데이터셋을 자동 축적한다는 내용은 결과와 향후 가능성을 구분해야 한다.

**시각:** 영상이 왼쪽 본문의 오른쪽 부분을 덮어 문장을 읽을 수 없다. 영상 대표 화면에는 아직 적재 결과가 나타나지 않아 정지 상태의 슬라이드만으로 성과를 알기 어렵다.

**수정:** ‘2차 미션: 3층 적재 성공’이라는 독립 결과 장으로 변경했다. 영상과 텍스트 영역을 완전히 분리하고, 세 블록이 적층된 마지막 장면을 대표 화면으로 사용했다. 오른쪽에는 현재 성과, 4층 이상에서의 제약, 다음 검증을 배치했다. 적재 영상은 H.264 호환본으로 변환하되 영상 내용과 원본 오디오를 보존했다.

### 원본 14장 — 감사와 Q&A → 수정본 14장

**내용:** 감사 인사만 있어 질의응답 중 프로젝트 주제와 담당자를 다시 확인하기 어렵다.

**시각:** ‘감사합니다’와 큰 로고가 면적을 많이 차지하며 넓은 빈 공간이 남는다. 본문 장과 강조 크기의 차이가 크다.

**수정:** 감사 인사를 차분하게 줄이고 프로젝트 주제와 세 구성원의 핵심 역할을 넣었다. 앞의 표지와 같은 로고 크기, 선, 색을 사용했다.

## 디자인 적용 기준

- 16:9 화면비 유지, 제목 위치와 바닥글 위치 통일.
- Steel/Sky 계열의 남색 `#355872`, 보조 파랑 `#7AAACE`, 밝은 배경 `#F7F8F0` 사용.
- 본문 제목 27pt, 주요 설명 16–21pt, 핵심 수치와 제목 위계 구분.
- 원본 사진과 실제 영상 프레임 사용, 새로운 실험 장면 생성 없음.
- 텍스트와 주요 도식은 PowerPoint에서 직접 편집 가능한 개체로 구성.
- 복잡한 수치표를 본문에 반복하지 않고 발표자 노트에 조건과 근거 보존.
