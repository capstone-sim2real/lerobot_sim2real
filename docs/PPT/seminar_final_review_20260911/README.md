## 적용 내용

본문 날짜와 불필요한 설정 나열을 줄이고 5개 블록의 운반 및 배치, 3층 적재 성공을 결과의 중심에 배치했다. 기술 선택, 시스템 구조, 핵심 구현, 실제 결과, 남은 검증 순서로 재정렬했다.

Steel/Sky 계열 색상과 Noto Sans CJK KR 서체를 사용했다. 제목과 본문, 주요 도식은 PowerPoint 개체로 편집할 수 있다. 이미지로 슬라이드 전체를 평탄화하지 않았다.

원본의 동작 영상과 관제 영상은 바이트 단위로 보존했다. 적재 영상은 재생 호환성을 위해 HEVC에서 H.264로 변환했다. 1920×1080 해상도와 전체 1,631프레임, 원본 AAC 오디오를 유지했으며 프레임률 정규화로 영상 길이에 0.03초 차이가 있다.

## 재생성

원본 PPTX와 이 폴더의 `assets/`, `analysis/` 자료가 있는 환경에서 실행한다.

```bash
uv run --no-project --with python-pptx --with pillow python build_revised.py
```

이 명령은 PPTX와 발표자 노트를 생성한다. PDF와 렌더링 이미지는 별도 LibreOffice/Poppler 변환 산출물이다.

실제 발표용 Microsoft PowerPoint에서의 클릭 재생 및 프로젝터 출력은 이번 검증 범위에 포함되지 않는다.
