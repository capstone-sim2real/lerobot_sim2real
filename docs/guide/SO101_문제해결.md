# SO-101 문제해결

SO-101 세팅과 실행 중 자주 만나는 문제를 모은 문서입니다. 기본 설치 순서는 [SO101_세팅가이드.md](./SO101_세팅가이드.md)를 먼저 따릅니다.

## Permission Denied

증상:

```text
PermissionError: [Errno 13] Permission denied: '/dev/serial/by-id/...'
```

원인:

```text
USB serial 장치가 root:dialout 소유인데 현재 사용자가 dialout 그룹에 없음
```

확인:

```bash
id
ls -l /dev/serial/by-id/* /dev/ttyACM*
```

해결:

```bash
sudo usermod -aG dialout "$USER"
```

로그아웃 후 다시 로그인하고 `id` 출력에 `dialout`이 있는지 확인합니다.

## Fish Activate 실패

증상:

```text
Unsupported use of '='. In fish, please use 'set ...'
```

fish에서는 bash용 `activate`가 아니라 fish용 파일을 사용합니다.

```fish
cd ~/lerobot_sim2real
source .venv/bin/activate.fish
```

가상환경을 켜지 않고 직접 실행해도 됩니다.

```fish
uv run lerobot-find-cameras
```

## uv 명령이 안 잡힘

증상:

```text
uv: command not found
```

설치:

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.bashrc
source ~/.bashrc
uv --version
```

fish를 쓰는 경우:

```fish
fish_add_path ~/.local/bin
uv --version
```

## 모터가 안 보임

증상:

```text
Full found motor list: {}
```

또는:

```text
Missing motor IDs
```

확인할 것:

```text
1. 로봇팔 전원
2. 서보 데이지체인 케이블
3. USB serial 어댑터 연결
4. 보드와 첫 번째 모터 사이 케이블
5. leader/follower 포트가 문서와 일치하는지
```

다시 스캔:

```bash
cd ~/lerobot_sim2real
so101-scan-motors
```

정상이라면 각 팔에서 모터 ID `1, 2, 3, 4, 5, 6`이 모두 보여야 합니다.

## 첫 실행은 실패하고 두 번째 실행은 됨

가끔 시작할 때 특정 서보가 한 번 응답하지 않을 수 있습니다. 모터 스캔 후 다시 실행하면 정상 동작하는 경우가 있습니다.

반복해서 발생하면 전원, USB 케이블, 서보 데이지체인 케이블을 먼저 확인합니다.

## 포트 번호가 바뀜

`/dev/ttyACM0`, `/dev/ttyACM1` 번호는 재부팅이나 재연결 후 바뀔 수 있습니다. 가능하면 `/dev/serial/by-id/...` 경로를 사용합니다.

확인:

```bash
ls -l /dev/serial/by-id/*
```

현재 스크립트의 기본 포트:

```text
leader:
/dev/serial/by-id/usb-1a86_USB_Single_Serial_5AE6085435-if00

follower:
/dev/serial/by-id/usb-1a86_USB_Single_Serial_5AE6086462-if00
```

## 카메라 노드가 바뀜

USB 카메라는 재부팅이나 재연결 후 `/dev/video0`, `/dev/video2` 번호가 바뀔 수 있습니다.

확인:

```bash
ls /dev/video*
cd ~/lerobot_sim2real
uv run lerobot-find-cameras
```

원격 송출 문제는 [SO101_원격카메라.md](./SO101_원격카메라.md)의 트러블슈팅을 확인합니다.

## Task 1 dry-run 또는 실행이 시작되지 않음

`Task 1 requires zone_polygon_mm`이면 현재 venue calibration에 target zone이
등록되지 않은 것입니다.

```bash
so101-zone-calibrate
so101-zone-calibrate --write
so101-run --task 1 --dry-run
```

`Task-1 slot ... is outside the IK gate`이면 모터를 움직이기 전에 슬롯 IK 검사가
실패한 것입니다. 카메라/zone 좌표가 현재 설치와 일치하는지 먼저 확인하고,
실장비에서 검증하지 않은 보정값을 즉시 활성 설정으로 덮어쓰지 않습니다.

## 카메라 snapshot이 stale 또는 반복됨

Task 1 완료 판정은 fresh frame만 셉니다. 카메라 서버가 멈췄거나 같은 sequence를
반복하면 외부 블록이 없어도 5초 완료 타이머가 진행되지 않습니다.

```bash
curl -fsS http://127.0.0.1:8090/health
curl -o /tmp/shoulder.jpg http://127.0.0.1:8090/snapshot/shoulder.jpg
```

서버 로그와 `/health`를 확인하고, `/dev/video0`을 다른 프로세스가 소유하고 있지
않은지 점검합니다.
