# SO-101 블록 쌓기 모방학습 로컬 실험 가이드

이 문서는 SO-101 기본 세팅이 끝난 상태에서 `데이터 수집 -> 데이터 검수 -> ACT 학습 -> 실제 로봇 rollout -> 실패 보강` 루프를 로컬에서 반복하는 방법을 정리합니다.

기본 설치, USB 권한, 캘리브레이션, 원격 카메라 송출은 아래 문서를 먼저 따릅니다.

- [SO101_세팅가이드.md](./SO101_세팅가이드.md)
- [SO101_문제해결.md](./SO101_문제해결.md)
- [SO101_원격카메라.md](./SO101_원격카메라.md)

전제 경로:

```text
LeRobot:  ~/lerobot
프로젝트: ~/lerobot_sim2real
데이터:   ~/lerobot_data
출력:     ~/lerobot_outputs
```

## 1. 목표와 실험 단계

처음부터 경기용 5블록 탑쌓기를 바로 해결하지 않습니다. 먼저 쉬운 성공 데이터를 만들고 실패 원인을 분리합니다.

추천 단계:

1. 단일 블록을 집어 지정 영역 안에 내려놓기
2. 여러 시작 위치의 단일 블록 pick-and-place 안정화
3. 높이 쌓지 않고 지정 영역 안 기준 위치에 가지런히 놓기
4. 2개 블록 쌓기
5. 3개 이상 쌓기
6. 최종 5개 블록 경기 흐름

1차 데이터셋은 `블록을 모아서 대충 던져놓기`가 아니라 `지정 영역의 일정한 위치/자세로 정확히 내려놓기`를 목표로 합니다. 그래야 이후 쌓기 단계에서 필요한 정렬 습관이 생깁니다.

## 2. 사전 준비 체크리스트

실험 시작 전 아래가 되어 있어야 합니다.

```bash
cd ~/lerobot_sim2real
./scripts/so101_scan_motors.sh
./scripts/so101_teleop.sh 30
```

확인할 것:

```text
1. leader/follower 모터 ID 1-6 응답
2. 캘리브레이션 완료
3. 30 Hz 텔레오퍼레이션 정상
4. /dev/video0, /dev/video2 카메라 역할 확인
5. 팔 주변 충돌 위험 제거
```

모터, 포트, 권한 문제가 있으면 [SO101_문제해결.md](./SO101_문제해결.md)를 봅니다.

모방학습용 추가 의존성이 필요하면 LeRobot 쪽에서 맞춥니다.

```bash
cd ~/lerobot
uv sync --extra feetech --extra core_scripts --extra training --extra dataset_viz
```

좌표 기준 키보드 조작이나 kinematics가 필요하면:

```bash
uv sync --extra feetech --extra core_scripts --extra training --extra dataset_viz --extra kinematics
```

Orin에서는 JetPack에 맞는 PyTorch가 중요합니다. 설치 중 PyTorch를 크게 바꾸려 하면 중단하고 먼저 확인합니다.

```bash
cd ~/lerobot
source .venv/bin/activate
python -c "import torch; print(torch.__version__, torch.cuda.is_available())"
```

## 3. 공통 환경 변수

로컬 실험 데이터는 Hub에 올리지 않고 `~/lerobot_data`에 모읍니다.

```bash
export HF_LEROBOT_HOME=$HOME/lerobot_data
mkdir -p "$HF_LEROBOT_HOME"
```

처음 추천 데이터셋 이름:

```bash
export DATASET_REPO_ID=local/so101_pick_place_v1
```

기록 후 최신 실제 데이터셋 ID를 잡습니다. LeRobot이 새 기록 세션에 시간 스탬프를 붙일 수 있기 때문입니다.

```bash
cd ~/lerobot_sim2real
./scripts/so101_learn.sh latest-dataset
```

카메라 설정:

```bash
export SO101_CAMERAS='{shoulder: {type: opencv, index_or_path: /dev/video0, width: 640, height: 480, fps: 30, fourcc: MJPG}, wrist: {type: opencv, index_or_path: /dev/video2, width: 640, height: 480, fps: 30, fourcc: MJPG}}'
```

프레임이 불안정하면 새 데이터셋부터 해상도와 FPS를 낮춥니다.

```bash
export SO101_CAMERAS='{shoulder: {type: opencv, index_or_path: /dev/video0, width: 320, height: 240, fps: 15, fourcc: MJPG}, wrist: {type: opencv, index_or_path: /dev/video2, width: 320, height: 240, fps: 15, fourcc: MJPG}}'
```

## 4. 에피소드 기록

화살표 키로 에피소드를 조기 종료/재녹화하려면 키보드 이벤트를 받을 수 있는 로컬 데스크톱 세션에서 실행하는 것이 가장 안정적입니다. SSH/headless 환경에서는 `--dataset.episode_time_s`를 짧게 잡고 한 에피소드씩 기록합니다.

에피소드 1개 기록:

```bash
cd ~/lerobot_sim2real
./scripts/so101_learn.sh record
```

녹화 중 조작:

```text
오른쪽 화살표(->): 현재 에피소드 일찍 끝내고 저장
왼쪽 화살표(<-): 현재 에피소드 버리고 다시 녹화
Esc: 전체 기록 중지
Ctrl+C: 응급 중지
```

기존 데이터셋에 에피소드 1개 추가:

```bash
cd ~/lerobot_sim2real
SO101_RESUME=1 ./scripts/so101_learn.sh record
```

여러 에피소드를 연속 기록:

```bash
cd ~/lerobot_sim2real
SO101_RESUME=1 SO101_NUM_EPISODES=5 SO101_RESET_TIME_S=15 ./scripts/so101_learn.sh record
```

에피소드 사이 reset 시간에는 블록 위치와 로봇 시작 자세를 정리합니다.

실험 조건은 환경변수로 바꿉니다.

```bash
DATASET_REPO_ID=local/so101_stack2_v1 \
SO101_TASK="Pick up one block and place it on top of the base block." \
./scripts/so101_learn.sh record
```

## 5. 데이터셋 검수

데이터셋 정보 보기:

```bash
cd ~/lerobot
source .venv/bin/activate

export HF_LEROBOT_HOME=$HOME/lerobot_data
export ACTUAL_REPO_ID=$(cd ~/lerobot_sim2real && ./scripts/so101_learn.sh latest-dataset)

lerobot-edit-dataset \
  --repo_id "$ACTUAL_REPO_ID" \
  --operation.type info \
  --operation.show_features true
```

특정 에피소드 영상/관절값 보기:

```bash
lerobot-dataset-viz \
  --repo-id "$ACTUAL_REPO_ID" \
  --episode-index 0 \
  --mode local
```

원격/headless 환경이면 `.rrd` 파일로 저장합니다.

```bash
lerobot-dataset-viz \
  --repo-id "$ACTUAL_REPO_ID" \
  --episode-index 0 \
  --save 1 \
  --output-dir ~/dataset_viz
```

특정 에피소드 재생:

```bash
lerobot-replay \
  --robot.type=so101_follower \
  --robot.port=/dev/serial/by-id/usb-1a86_USB_Single_Serial_5AE6086462-if00 \
  --robot.id=my_follower \
  --robot.max_relative_target=10 \
  --dataset.repo_id="$ACTUAL_REPO_ID" \
  --dataset.episode=0
```

주변을 비우고 짧은 에피소드부터 재생합니다.

나쁜 에피소드 삭제:

```bash
export FILTERED_REPO_ID=local/so101_pick_place_v1_filtered

lerobot-edit-dataset \
  --repo_id "$ACTUAL_REPO_ID" \
  --new_repo_id "$FILTERED_REPO_ID" \
  --operation.type delete_episodes \
  --operation.episode_indices "[3]"
```

같은 위치에 다시 쓰면 원본은 보통 `_old` 백업 폴더로 이동됩니다.

```bash
lerobot-edit-dataset \
  --repo_id "$ACTUAL_REPO_ID" \
  --new_repo_id "$ACTUAL_REPO_ID" \
  --operation.type delete_episodes \
  --operation.episode_indices "[3]"
```

## 6. ACT 학습

처음에는 5개 에피소드만으로 학습이 도는지 확인합니다.

```bash
cd ~/lerobot_sim2real
./scripts/so101_learn.sh train-overfit
```

성공 기준:

```text
학습이 에러 없이 돈다.
loss가 대체로 내려간다.
$TRAIN_DIR/checkpoints/last/pretrained_model 이 생긴다.
```

50 에피소드 이상 모이면 첫 실제 모델을 학습합니다.

```bash
cd ~/lerobot_sim2real
TRAIN_DIR=$HOME/lerobot_outputs/act_so101_pick_place_v1 \
BATCH_SIZE=4 \
NUM_WORKERS=2 \
TRAIN_STEPS=20000 \
SAVE_FREQ=5000 \
LOG_FREQ=100 \
./scripts/so101_learn.sh train-overfit
```

Orin 메모리가 부족하면:

```text
batch_size 4 -> 2
num_workers 2 -> 0
카메라 해상도 640x480 -> 320x240로 새 데이터셋 수집
```

학습 재개:

```bash
cd ~/lerobot
source .venv/bin/activate

lerobot-train \
  --resume=true \
  --config_path="$TRAIN_DIR/checkpoints/last/pretrained_model/train_config.json"
```

## 7. Rollout 테스트

처음에는 블록을 잡기 전 주변을 비우고 5~10초만 돌립니다.

```bash
cd ~/lerobot_sim2real
./scripts/so101_learn.sh rollout
```

문제가 없으면 `--duration=30`으로 늘립니다.

```bash
SO101_ROLLOUT_DURATION=30 ./scripts/so101_learn.sh rollout
```

성공률은 처음에는 손으로 표를 만들어도 충분합니다.

```text
정책: act_so101_pick_place_v1
데이터: so101_pick_place_v1, 50 episodes
카메라: shoulder /dev/video0, wrist /dev/video2
테스트: 10회

1 성공
2 실패 - 그리퍼 높이 높음
3 실패 - 블록 왼쪽으로 밀림
...
성공률: 6/10 = 60%
```

## 8. 실패 보강 루프

처음 1주차 루프:

```text
1. 모터/카메라 확인
2. pick-and-place 5 episodes 기록
3. dataset-viz로 5 episodes 확인
4. overfit 학습 1000 steps
5. rollout 10초
6. pick-and-place 20~50 episodes까지 추가
7. 나쁜 episode 삭제
8. ACT 20000 steps 학습
9. 10회 성공률 측정
10. 실패 유형만 보강 수집
```

실패 유형별 보강:

```text
블록 위치를 못 찾음 -> 시작 위치 다양화, shoulder 카메라 확인
접근은 하나 높이가 안 맞음 -> wrist 카메라에 파지 순간이 잘 보이게 수집
잡고 놓침 -> 그리퍼 닫는 타이밍과 들어올리는 속도 시연 보강
목표 위치에서 흐트러짐 -> 내려놓기 직전 정렬/정지 동작 보강
```

권장 에피소드 수:

```text
파이프라인 확인: 5 episodes
첫 overfit:       5~10 episodes
첫 실제 모델:    50 episodes
안정화:          100~200 episodes
2블록 쌓기:       별도 50 episodes부터 시작
```

## 9. 쌓기 단계로 넘어가는 기준

다음 조건을 만족하면 2블록 쌓기로 넘어갑니다.

```text
단일 블록 pick-and-place 성공률이 같은 조건에서 70% 이상
블록을 목표 영역 안에 놓는 위치 오차가 눈에 띄게 줄어듦
손목 카메라에서 파지/내려놓기 순간이 안정적으로 보임
나쁜 episode를 삭제하고 다시 학습하는 루프가 익숙함
```

2블록 쌓기 데이터셋 이름 예:

```bash
export DATASET_REPO_ID=local/so101_stack2_v1
```

작업 문장:

```text
Pick up one block and place it on top of the base block.
```

처음에는 시작 조건을 강하게 고정합니다.

```text
base block은 항상 지정 영역 중앙에 둔다.
두 번째 블록만 집어서 올린다.
카메라 위치는 pick-and-place와 동일하게 고정한다.
성공 후 5초 유지까지 사람이 확인한다.
```

그 다음에 한 에피소드 안에서 `첫 블록을 바닥에 놓고, 두 번째 블록을 그 위에 쌓기`로 확장합니다.

## 11. 운영 원칙

- 한 데이터셋 안에서는 카메라 위치, 해상도, task 정의를 중간에 바꾸지 않는다.
- 실패한 시연은 학습 전에 삭제한다.
- 성공 데이터만 모으되, 시작 위치와 블록 자세는 조금씩 다양화한다.
- 처음에는 빠른 동작보다 일정하고 재현 가능한 시연이 더 좋다.
- 쌓기보다 먼저 `정확히 내려놓기`를 학습시킨다.
- 모델 성능이 애매하면 모델 구조를 키우기 전에 데이터를 눈으로 다시 본다.
- 매 실험마다 데이터셋 ID, 에피소드 수, 학습 steps, 성공률, 대표 실패 유형을 적는다.
