# 실험 기록

실측 데이터는 날짜별로 보관한다. 실패 기록도 유지한다. 현재 적용된 설정은
`src/configs/`에서 확인하고, 실험 후보 파일을 활성 설정으로 오인하지 않는다.

- [날짜 미확인 이전 자료](legacy/calibration/README.md)
- [2026-09-08 세션](2026-09-08/session_20260908_AcC1p4/README.md):
  카메라 고정, 9점 캘리브레이션, Task1, FK 비교, 노란 블록 재파지.
- 각 세션의 `runtime_scripts/`는 당시 코드 원본, `archive/`는 이전 백업이다.
- 재사용 실행 도구는 `src/tools/`에 둔다.

과거 기록의 경로 문자열은 원본을 보존한다. 새 세션은 결과 폴더를 명시적으로
지정한다. 라이브 관절 로그와 IPC 파일은 추적하지 않는 `var/so101/`에 둔다.
